# Ihre Piwigo-Galerie selbst hosten

Zur Erinnerung: Sie können Piwigo auf zwei Arten nutzen:

- Sie laden die kostenlose Software Piwigo auf der Website [piwigo.org](https://de.piwigo.org/) herunter und installieren sie bei Ihrem Webhoster;
- Oder Sie schliessen ein „Cloud“-Abonnement bei [Piwigo Cloud](https://de.piwigo.org/piwigo-bekommen) ab, das Hosting, Updates und Zugang zum Support umfasst.

**In diesem Abschnitt finden Sie alle Artikel der Dokumentation, die Benutzer einer selbst gehosteten Version betreffen.**

Die hier aufgeführten Artikel betreffen also keine Kunden mit einem Piwigo-Cloud-Abonnement.
