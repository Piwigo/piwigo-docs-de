# Automatisches Update

Dies ist die empfohlene Methode, um Ihr Piwigo auf die neueste Version zu aktualisieren. Sie ist so einfach, dass Sie keine Ausrede mehr haben, Ihre Updates zu vergessen oder aufzuschieben. Es dauert wirklich weniger als 1 Minute, bis die neueste und sicherste Piwigo-Version läuft.

!!! info "Erstellen Sie Backups!"
    Halten Sie immer ein Backup Ihrer Datenbank und Ihrer Dateien bereit. Am besten lassen Sie diese regelmässig automatisch erstellen. Falls während des Updates etwas schiefgeht, können Sie so ein Backup wiederherstellen.

## Ein einziger Schritt

Gehen Sie zu Administration > Werkzeuge > Aktualisierungen und folgen Sie der Anleitung.

??? note "Wenn Sie eine ältere Version als Piwigo 2.3.0 verwenden"
    === "Piwigo 2.1.x oder 2.2.x"
    
        1. Gehen Sie zu Administration > Plugins > Verwaltung > Weitere Plugins und installieren Sie Piwigo Auto Upgrade. Wenn das Plugin bereits installiert ist, prüfen Sie unter Administration > Plugins > Verwaltung > Auf Aktualisierungen überprüfen, ob Sie die neueste Revision verwenden.
        2.  Gehen Sie zu Administration > Plugins > Verwaltung > Liste der Plugins, um dieses neue Plugin zu installieren und zu aktivieren.
        3.  Gehen Sie zu Administration > Plugins > Piwigo AutoUpgrade und folgen Sie der Anleitung.
    
    === "Piwigo 2.0.x"
    
        1.  Gehen Sie zu Administration > Erweitert > Plugins > Weitere Plugins und führen Sie eine automatische Installation von Piwigo Auto Upgrade durch. Wenn das Plugin bereits installiert ist, prüfen Sie, ob Sie die neueste Revision verwenden.
        2.  Gehen Sie zu Administration > Erweitert > Plugins, um dieses neue Plugin zu installieren und zu aktivieren.
        3.  Gehen Sie zu Administration > Erweitert > Plugins > Piwigo AutoUpgrade und folgen Sie der Anleitung. Sie können entweder auf die letzte Version desselben „Zweigs“ oder auf die allerneueste Piwigo-Version aktualisieren.
    
    === "Piwigo 1.7.x"
    
        1.  Laden Sie das Plugin Piwigo Auto Upgrade herunter und entpacken Sie es in Ihr Verzeichnis „plugins“.
        2.  Gehen Sie zu Administration > Erweitert > Plugins > Administration, klicken Sie beim Plugin „Piwigo AutoUpgrade“ auf die Aktion „Installieren“ und anschliessend auf die Aktion „Aktivieren“.
        3.  Gehen Sie zu Administration > Erweitert > Plugins > Piwigo AutoUpgrade und folgen Sie der Anleitung. Sie können entweder auf die letzte Version desselben „Zweigs“ oder auf die allerneueste Piwigo-Version aktualisieren.
    
    
    === "Älter als Piwigo 1.7.x"
    
        Wenn Sie eine ältere Version verwenden, folgen Sie bitte stattdessen der Anleitung [Manuelles Update](manuelles-update.md).
