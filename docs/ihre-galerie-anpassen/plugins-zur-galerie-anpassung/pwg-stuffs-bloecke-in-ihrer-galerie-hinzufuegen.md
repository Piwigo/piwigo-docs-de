# PWG Stuffs: Blöcke in Ihrer Galerie hinzufügen

Das Plugin **PWG Stuffs** bietet verschiedene Möglichkeiten, Blöcke zu Ihrer Galerie hinzuzufügen. Diese Blöcke ergänzen die bestehenden Seiten. Damit ist es ein sehr umfassendes Plugin zur Anpassung Ihrer Galerie.

Es wird hauptsächlich verwendet, um:

- eine Schlagwortwolke auf der Startseite hinzuzufügen
- einen Anmeldebereich auf der Startseite hinzuzufügen

---

## Einen Anmeldebereich auf der Startseite mit PWG Stuffs hinzufügen

Wenn Ihre Galerie zu 100 % privat ist, möchten Sie wahrscheinlich, dass sich Benutzer direkt auf der Startseite anmelden können.

Das ist mit dem Plugin **PWG Stuffs** möglich.

Öffnen Sie in den Einstellungen des Plugins PWG Stuffs den Tab „Block hinzufügen“. Wählen Sie in der Liste „Anmeldung“ und klicken Sie auf „Block hinzufügen“.

![Plugin PWG.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-889c76a3-me.jpg)

Nun sehen Sie die Konfigurationsoptionen Ihres Blocks. Hier können Sie den Titel Ihres Anmeldeblocks anpassen, festlegen, ob dieser Titel auf der Startseite angezeigt wird, und bestimmen, auf welchen Seiten der Block erscheint.

![Nouveau bloc.jpg](https://ressources.piwigo.com/picture?/1638/category/181-pwg_stuffs_adding_blocks_in_your_gallery)

Speichern Sie. Sie gelangen nun auf die Seite zur Verwaltung der Blöcke.

Wählen Sie bei „Hauptblock“ die Option „Auf der Startseite ausblenden“.

![Gérer les blocs.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-30d37c64-me.jpg)

Fertig! Ihre Startseite zeigt jetzt ein Anmeldeformular.

![Formulaire connexion.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-0bf39463-me.jpg)

Kehren wir zur Verwaltung der Blöcke zurück. Sie können einen hinzugefügten Block löschen, indem Sie auf das rote Kreuz klicken, und seine Einstellungen bearbeiten, indem Sie auf das Werkzeugsymbol klicken.

## Eine Schlagwortwolke auf der Startseite mit PWG Stuffs hinzufügen

Auch um eine Schlagwortwolke auf Ihrer Startseite oder einer anderen Seite Ihrer Galerie hinzuzufügen, verwenden Sie das Plugin PWG Stuffs.

Öffnen Sie in den Einstellungen des Plugins PWG Stuffs den Tab „Block hinzufügen“. Wählen Sie in der Liste „Schlagworte“ und klicken Sie dann auf „Block hinzufügen“.

![Bloc tags.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-d714fa7c-me.jpg)

Nun sehen Sie die Konfigurationsoptionen Ihres Blocks. Hier können Sie den Titel Ihres Blocks mit der Schlagwortwolke anpassen, festlegen, ob dieser Titel auf der Startseite angezeigt wird, und bestimmen, auf welchen Seiten der Block erscheint.

Sie können ausserdem zwischen 3 Anzeigeoptionen wählen:

- Schlagwortwolke
- Nach Anfangsbuchstaben gruppieren
- Cumulus-Modus verwenden (dafür muss das Plugin Cumulus Tag Clouds aktiviert sein. Dieses Plugin ist für Kunden von piwigo.com nicht verfügbar)

![Bloc tags config.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-5d29b359-me.jpg)

Wählen Sie die Option „Schlagwortwolke“ und speichern Sie.

Fertig! Ihre Startseite zeigt jetzt eine Schlagwortwolke.

![Nuage tags accueil.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4e9e6494-me.jpg)

Kehren wir zur Verwaltung der Blöcke zurück. Bearbeiten Sie den erstellten Block mit einem Klick auf das Werkzeugsymbol und wählen Sie nun die Option „Nach Anfangsbuchstaben gruppieren“.

Die Schlagworte sind jetzt nach Anfangsbuchstaben gruppiert und alphabetisch sortiert.

![Tags par lettre.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-8abb5e4c-me.jpg)

## Weitere Funktionen

Neben dem Anmeldeformular und der Schlagwortwolke können Sie mit dem Plugin PWG Stuffs weitere Blöcke zu Ihrer Galerie hinzufügen: 

- Persönlicher Block: fügt Text oder HTML-Inhalt Ihrer Wahl hinzu, zum Beispiel eine Willkommensnachricht.
- Letzte Kommentare: zeigt die neuesten Kommentare in der Galerie
- Zufällige Fotos: zeigt eine bestimmte Anzahl zufälliger Fotos aus der Galerie oder aus dem aktuellen Album
- Hervorgehobene Fotos: zeigt die Favoriten des Benutzers mit dem Status Webmaster
- Neueste Fotos: zeigt die neuesten Fotos der Galerie oder des aktuellen Albums (falls vorhanden)
- Am besten bewertet: zeigt eine bestimmte Anzahl der am besten bewerteten Fotos der Galerie oder des aktuellen Albums
- Am häufigsten angesehen: zeigt eine bestimmte Anzahl der am häufigsten angesehenen Fotos der Galerie oder des aktuellen Albums

## Zugriffsrechte für Blöcke

Sie können Zugriffsrechte einrichten, um die Anzeige der Blöcke je nach angemeldetem Benutzer anzupassen.

Öffnen Sie dazu in den Einstellungen von PWG Stuffs den Tab „Konfiguration“.

Sie können die Zugriffsrechte verwalten:

- nach [Benutzerstatus (oder -typ)](../../benutzer-verwalten/benutzerstatus.md)
- nach [Datenschutzstufe](../../benutzer-verwalten/datenschutzstufen.md)
- nach [Benutzergruppe](../../benutzer-verwalten/benutzergruppen.md)

Nehmen wir an, ein Block soll nur für anonyme Benutzer (die nicht in der Galerie angemeldet sind) angezeigt werden. In diesem Fall aktivieren wir die Rechte nach Benutzertyp.

![Config blocs PWG.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-0a7a7157-me.jpg)

In den Einstellungen eines Blocks können wir jetzt auswählen, welche Benutzer diesen Block sehen dürfen. In unserem Fall wählen wir nur „Gast“. So sehen nur Benutzer, die nicht angemeldet sind, diesen Block.

![Modifier bloc tags.jpg](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-88811045-me.jpg)

## Module abwechseln

Mit diesem Plugin können Sie die Inhalte Ihrer Galerie sehr weitgehend an die Benutzer anpassen.

Für jedes Modul können Sie nämlich festlegen, auf welcher Art von Seite es angezeigt wird, welche Benutzer es sehen, in welcher Zeile es erscheint und wie breit es ist. Durch das Zusammenspiel dieser Einstellungen können Sie zwei Module an derselben Stelle abwechselnd anzeigen.

Zum Beispiel:

- Modul 1 *EDITORIAL* (Anzeigeeinstellungen: Zeile A, 60 %, nur auf der Hauptseite, für alle sichtbar) könnte eine Einführung in Ihre Galerie enthalten.
- Daneben könnte Modul 2 *NEWS* (Anzeigeeinstellungen: Zeile A, 40 %, nur auf der Hauptseite, nur für angemeldete Benutzer sichtbar) neue Besucher dazu anregen, ein Konto zu erstellen, sofern das möglich ist.
- Modul 3 *WELCOME* (Anzeigeeinstellungen: Zeile A, 40 %, nur auf der Hauptseite, nur für angemeldete Benutzer sichtbar) könnte den Benutzernamen und eine Willkommensnachricht enthalten.

Beim Aufrufen der Galerie sieht der Benutzer oben links das *EDITORIAL* und rechts daneben die *NEWS*. Sobald er sich anmeldet, wird NEWS durch *WELCOME* ersetzt. Wenn er dann die Alben besucht, verschwinden diese Module, um mehr Platz für die Inhalte Ihrer Galerie zu schaffen.
