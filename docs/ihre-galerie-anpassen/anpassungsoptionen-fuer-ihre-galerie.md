# Anpassungsoptionen für Ihre Galerie

Sie können Ihre Piwigo-Galerie auf verschiedene Arten anpassen:

- Indem Sie ein [Erscheinungsbild](../erscheinungsbilder/index.md) Ihrer Wahl auswählen und einrichten
- Indem Sie [Plugins](../plugins/index.md) installieren
- Es lohnt sich aber auch, die verschiedenen Standard-Konfigurationsoptionen von Piwigo zu erkunden. Diese stellen wir in diesem Artikel vor.

Gehen Sie dazu im Administrationsbereich in das Menü Konfiguration > Optionen. In diesem Menü finden Sie verschiedene Anpassungsoptionen für Ihre Piwigo-Galerie an einem Ort.

## Tab „Allgemein“

Der erste Tab ist in mehrere Bereiche unterteilt.

### Grundeinstellungen

![Grundeinstellungen](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-6aa7ad20.jpg)

**Den Titel Ihrer Galerie ändern**

Hier legen Sie den Titel Ihrer Galerie fest. Er ist sozusagen der Name Ihrer Website und wird von Piwigo an mehreren Stellen verwendet.

Einige Erscheinungsbilder wie Bootstrap Darkroom zeigen den Galerie-Titel standardmässig auf allen Seiten an (siehe unten). Beim Standard-Erscheinungsbild Modus ist das nicht der Fall.

![Titel ändern](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-bc3dc9ac.jpg)

**Den Inhalt eines Banners festlegen**

Im Feld „Seitenbanner“ erstellen Sie ein Banner, das oben auf allen Seiten Ihrer Website angezeigt wird, wie im Beispiel unten.

![Banner mit Modus](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2cd18d15.jpg)

Mehr zum Erstellen von Bannern für Ihre Piwigo-Galerie erfahren Sie in diesem Artikel:

[Eigenes Banner](eigenes-banner-zur-galerie-hinzufuegen.md)

**Die Anzeigereihenfolge der Fotos ändern**

Hier können Sie auch die Reihenfolge ändern, in der Fotos auf den Seiten angezeigt werden. Standardmässig werden sie nach Upload-Datum (von neu nach alt), dann alphabetisch und nach ID sortiert. Sie können diese Reihenfolge aber anpassen.

### Zugriffsrechte

![Liste der Zugriffsrechte](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2d8c0809.jpg)

Hier legen Sie fest, ob Bewertungen in Ihrer Galerie aktiviert sind (Option „Bewertungen von Fotos erlauben“). [Mehr über Bewertungen erfahren](../kommentare-und-bewertungen/bewertungen-verwalten.md)

Ausserdem legen Sie hier fest, ob Benutzer selbst ein Konto erstellen dürfen (Option „Neuregistrierung von Benutzern erlauben“). [Mehr über Benutzer erfahren](../benutzer-verwalten/benutzer-erstellen-und-verwalten.md)

Schliesslich können Sie hier festlegen, ob Benutzer ihre Anzeigeeinstellungen in der Galerie selbst anpassen dürfen (indem Sie das Menü „Anpassen“ aktivieren oder nicht). [Mehr über Einstellungen erfahren](../benutzer-verwalten/benutzer-erstellen-und-verwalten.md)

### Verschiedenes

![Verschiedenes](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-c50ff7a8.jpg)

Die Optionen im Bereich „Verschiedenes“ betreffen nicht wirklich die Anpassung der Galerie. Es sind eher allgemeine Optionen, die für Piwigo als Ganzes gelten:

- erster Tag der Woche
- Speichern des Besuchsverlaufs
- ob die mobile App beworben wird
- Erscheinungsbild der versendeten E-Mails (hell oder dunkel)
- ob Duplikate beim Hochladen erkannt werden

## Tab „Anzeige“

In diesem Tab passen Sie Ihre Galerie mit vielen Optionen an, die Sie aktivieren oder deaktivieren können.

Er ist in mehrere Bereiche unterteilt.

### Hauptseite

![Optionen Hauptseite](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-22be9496.jpg)

Der Bereich „Hauptseite“ enthält verschiedene Optionen, mit denen Sie die in Ihrer Galerie verfügbaren Aktionen anpassen.

Hier legen Sie zum Beispiel fest, wie viele Alben pro Seite in Ihrer Galerie angezeigt werden. Standardmässig sind es 12. Wenn Sie viele Alben haben, können Sie mehr anzeigen.

Hier können Sie auch die meisten Symbole auf der Startseite Ihrer Galerie oder auf einer Albumseite aktivieren oder deaktivieren.

### Fotoseite

Der Bereich „Fotoseite“ enthält die Aktionen und Anzeigeoptionen, die Sie auf einer Fotoseite aktivieren oder deaktivieren können.

![Optionen Fotoseite](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-88cafede.jpg)

So passen Sie die für ein Foto verfügbaren Aktionen an, zum Beispiel ob der Download aktiviert ist.

Sie können auch festlegen, ob die Navigationsleiste aktiviert ist, mit der man durch die Fotos eines Albums blättert.

Schliesslich legen Sie fest, ob das Galeriemenü auf einer Fotoseite angezeigt wird (standardmässig ist es ausgeblendet).

### Fotoeigenschaften

Im Bereich „Fotoeigenschaften“ wählen Sie die Eigenschaften aus, die im Informationsbereich einer Fotoseite angezeigt werden.

![Fotoeigenschaften](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-959b6a38.jpg)

[Mehr über Eigenschaften erfahren](../fotos-importieren-und-verwalten/eigenschaften-und-metadaten-von-fotos.md)

## Das Aussehen Ihrer Galerie über die Einstellungen anpassen

Es gibt noch eine weitere, oft unbekannte Möglichkeit, einige Anzeigeeinstellungen Ihrer Galerie zu ändern: die Benutzereinstellungen.

Mit diesen Einstellungen passen Sie zum Beispiel Folgendes an:

- die Anzahl der Fotos pro Seite in einem Album
- den Anzeigezeitraum für das Menü „Neueste Fotos“
- die Anzeige der Unteralben als Baumstruktur im Navigationsmenü
- usw.

Die Einstellungen können für jeden Benutzer unterschiedlich sein. Als Administrator können Sie aber:

- die Standardeinstellungen für jeden neuen Benutzer festlegen
- die Einstellungen für den Benutzer „Gast“ festlegen (anonyme, nicht angemeldete Besucher Ihrer Galerie)
- Ihre eigenen Einstellungen und die anderer Benutzer bearbeiten

[Mehr über Einstellungen erfahren](../benutzer-verwalten/benutzer-erstellen-und-verwalten.md)
