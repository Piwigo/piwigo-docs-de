# Das Erscheinungsbild Modus

## Vorstellung des Erscheinungsbilds Modus

Modus ist das Erscheinungsbild, das in Piwigo standardmässig aktiviert ist.

Es ist ein modernes Erscheinungsbild und garantiert die Kompatibilität mit den meisten Plugins.

Seine Merkmale:

- *responsives* Erscheinungsbild, das mit allen Bildschirmgrössen funktioniert
- grosse, quadratische Vorschaubilder für die Alben
- horizontale Menüleiste
- automatische Erkennung der passenden Fotogrösse für die Anzeige
- Unterstützung von Bildschirmen mit „hoher Pixeldichte“ (z. B. Retina) durch eine eigene Auswahl der Fotogrösse
- SVG-Symbole (Symbole, die bei jeder Zoomstufe scharf bleiben).

## Die Farben von Modus anpassen

Modus bietet 18 verschiedene Farbschemas.

Um Ihres auszuwählen, aktivieren Sie zuerst das Erscheinungsbild Modus im Administrationsbereich (Konfiguration > Erscheinungsbilder) und klicken Sie dann auf die Schaltfläche „Konfiguration“.

![Activation thème Modus.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-a9bb2538.jpg)

Nun sehen Sie die verschiedenen verfügbaren *Skins* bzw. Farbschemas.

Klicken Sie auf die Schaltfläche „Vorschau“, wenn Sie die Vorschau vergrössern möchten.

Klicken Sie auf den gewünschten Stil und dann auf „Einstellungen sichern“: Schon können Sie sich das Ergebnis in Ihrer Galerie ansehen!

![Liste thèmes Modus.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-80c0803e.jpg)

## Optionen von Modus

Die Konfiguration des Erscheinungsbilds Modus bietet weitere Optionen.

![Réglages miniatures.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-bb92d8e2.jpg)

### Vorschaubilder der Alben anpassen

Standardmässig zeigt Modus für Alben quadratische Vorschaubilder mit einer Seitenlänge von 250 px an.

Sie können die Option „Quadratische Vorschaubilder“ abwählen: Die Alben werden dann als grosse Blöcke angezeigt, in denen auch die Albumbeschreibungen erscheinen.

![Option annulée.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-7e524849.jpg)

Sie können die quadratischen Vorschaubilder auch beibehalten und nur ihre Grösse ändern.

### Vorschaubilder der Fotos anpassen

In einer Fotoliste zeigt Modus standardmässig Vorschaubilder in der Grösse XXS an.

![Miniatures normales.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-ed7f3dbb.jpg)

Wenn Sie möchten, können Sie die Standardgrösse der Vorschaubilder ändern.

Hier einige Beispiele.

- Vorschaubilder im quadratischen Format:
    
    ![Miniatures carrées.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-23bb1683.jpg)
    
- Vorschaubilder im Format „Vorschaubild“:
    
    ![Miniatures miniatures.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-908a6eb1.jpg)
    
- Vorschaubilder im Format S:
    
    ![Miniatures S.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2ee1cb31.jpg)
    

Diese Option lässt sich für Bildschirme mit hoher Pixeldichte (Retina) separat einstellen.

### Ein Banner hinzufügen

In Modus können Sie die Option „Seitenbanner anzeigen“ aktivieren.

Dadurch wird oberhalb des Menüs Ihrer Galerie ein Banner angezeigt.

![Bannière.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-9cf5c79c.jpg)

Den Inhalt dieses Banners (Text oder Bild) bearbeiten Sie im Administrationsbereich von Piwigo unter Konfiguration > Optionen.

![Réglages bannière.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-c72ee89c.jpg)
