# Das Erscheinungsbild Bootstrap Darkroom

## Vorstellung des Erscheinungsbilds Bootstrap Darkroom

**Bootstrap Darkroom** wurde von Thomas Kuther entwickelt. Es ist ein modernes Erscheinungsbild mit vielen Funktionen, das sich gut für mobile Geräte eignet. 

Seine Merkmale:

- Über 30 Farbschemas, um Ihre Galerie anzupassen
- Eine schöne Vollbild-Diashow mit automatischer Wiedergabe
- 100 % responsiv, passt sich also automatisch an alle Bildschirmgrössen an
- Einfaches Blättern in Ihren Alben mit einem Foto-Karussell
- Viele anpassbare Optionen…

![Page accueil BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-b2d5d1e8.jpg)

## Die Farben von Bootstrap Darkroom anpassen

Bootstrap Darkroom bietet über 30 verschiedene Farbschemas.

Um Ihres auszuwählen, aktivieren Sie zuerst das Erscheinungsbild Bootstrap Darkroom im Administrationsbereich (Konfiguration > Erscheinungsbilder) und klicken Sie dann auf die Schaltfläche „Konfiguration“.

![BD Configuration.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-9c15ce03.jpg)

In der Dropdown-Liste „Theme“ sehen Sie dann die verschiedenen verfügbaren Farbschemas. Wählen Sie ein Farbschema aus, um eine Vorschau anzuzeigen.

![Choix couleurs BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-88e31e67.jpg)

Speichern Sie die Einstellungen: Das gewählte Farbschema wird auf Ihre Galerie angewendet.

## Optionen von Bootstrap Darkroom

Die Konfiguration des Erscheinungsbilds Bootstrap Darkroom bietet viele weitere Optionen, verteilt auf 3 Registerkarten.

### Registerkarte 1: Aussehen

![Page 1 BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-6408d62f.jpg)

**Layout in voller Breite**

Mit der Option „volle Breite“ füllt Ihr Inhalt den ganzen Platz auf der Seite aus, egal wie gross der Bildschirm ist.

**Website-Logo**

Damit zeigen Sie oben links ein Logo statt des Namens der Website an.

Wenn Sie diese Option aktivieren, müssen Sie im Feld „Pfad“ den relativen Pfad zum Bild in Ihrer Piwigo-Galerie angeben. Wenn Sie Hilfe brauchen und Kunde von Piwigo Cloud sind, wenden Sie sich an den Support.

**Seitenkopf (Banner)**

Sie können Ihrer Galerie ein Banner hinzufügen. Dafür stehen Ihnen zwei Banner-Stile zur Verfügung:

- Mit dieser Option erstellen Sie auf der Startseite Ihrer Galerie ein Banner im „Jumbotron-Stil“. Der Inhalt des Banners wird in HTML im Menü Konfiguration > Optionen festgelegt. Er kann einen Titel, Text, ein Bild, eine Schaltfläche usw. enthalten. Mehr über den Bereich zum Erstellen des Seitenbanners erfahren Sie in [diesem Artikel](../ihre-galerie-anpassen/anpassungsoptionen-fuer-ihre-galerie.md).
    
    ![Bannière BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4dc4189a.jpg)
    

- Mit dieser Option verwenden Sie ein Bild aus Ihrer Piwigo-Galerie als Hintergrund des Banners. Wenn Sie möchten, können Sie dieses Bild in voller Höhe anzeigen. Der Text, der darüber erscheint, wird im Menü Konfiguration > Optionen festgelegt.
    
    ![Bannière photo.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-5d35b47a.jpg)
    

Mehr über das Erstellen von Bannern in Piwigo erfahren Sie in diesem Artikel:

[Eigenes Banner](../ihre-galerie-anpassen/eigenes-banner-zur-galerie-hinzufuegen.md)

**Aussehen der Kategorienseite (Alben)**

Wenn Sie möchten, können Sie die Alben als senkrechte Liste mit quadratischem Vorschaubild anzeigen, wie beim mobilen Erscheinungsbild Smart Pocket.

Sie können diese Option für alle Bildschirme oder nur für mobile Geräte aktivieren.

![Page accueil BD liste.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-84c4ebcf.jpg)

**Aussehen der Vorschaubildseite (Fotos)**

Mit mehreren Optionen können Sie ändern, wie Fotos auf Listenseiten (etwa auf der Seite eines Albums) aussehen.

- Bildunterschrift anzeigen
- Für Bilder die Beschreibung statt des Titels verwenden

Sie können auch festlegen, was passiert, wenn ein Benutzer auf ein Bild klickt.

Standardmässig öffnet ein Klick auf ein Bild die Detailseite des Bildes. Stattdessen kann das Bild auch in einem Pop-in-Fenster als Diashow angezeigt werden. Diese Option lässt sich für alle Bildschirme oder nur für mobile Geräte aktivieren.

![fr-bootstrap-diaporama.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-a085eaaa.png)

**Aussehen der Bildseite**

Die Detailinformationen des Bildes (Bewertung, Datum des Hochladens, Schlagworte, EXIF-Daten usw.) können Sie auf verschiedene Arten anzeigen:

- Kartenraster unter dem Bild (Standard)
    
    ![Affichage données BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-29ae99f0.jpg)
    
- Registerkarten unter dem Bild
    
    ![Affichage différent BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-3825e2e2.jpg)
    
- Seitenleiste (Informationsleiste links vom Bild, die der Benutzer ein- und ausblenden kann)
    
    ![Troisième affichage.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-0db1785e.jpg)
    
- Deaktiviert (in diesem Fall werden die Informationen nicht angezeigt).

**Eigenes CSS**

Im Feld „Custom CSS“ können Sie eigenen CSS-Code hinterlegen.

### Registerkarte 2: Komponenten

Die zweite Konfigurations-Registerkarte von Bootstrap Darkroom bietet weitere Optionen, um das Aussehen Ihrer Galerie anzupassen.

![Deuxième page configuration BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-ca914497.jpg)

**Einstellungen für Slick Carousel**

Standardmässig zeigt Bootstrap Darkroom auf der Seite eines Bildes ein Karussell an, mit dem Benutzer durch die anderen Bilder desselben Albums blättern können. 

Es stehen mehrere Optionen zur Verfügung:

- Karussell aktivieren oder deaktivieren
- Lazyload oder OnDemand: die Lademethode der Bilder ändern
- Endlosschleife: die Bilder des Karussells endlos durchlaufen lassen
- Zentriermodus: das aktuelle Bild in der Mitte des Karussells anzeigen

![Image au centre BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-25fdff09.jpg)

**Einstellungen für PhotoSwipe**

Standardmässig verwendet Bootstrap Darkroom die Komponente PhotoSwipe, um eine Diashow im Vollbildmodus anzuzeigen. 

Sie können sie deaktivieren, wenn Sie eine andere Diashow-Komponente verwenden möchten:

- die Standard-Diashow von Piwigo
- die Diashow Fotorama (dafür müssen Sie das Plugin Fotorama aktivieren)

Sie können auch das Intervall festlegen, in dem die Diashow weiterblättert (standardmässig 3500 Millisekunden).

**Schnellsuche**

Mit dieser Option zeigen Sie in der Navigationsleiste Ihrer Galerie ein Feld für die Schnellsuche an.

![Barre de recherche BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-adc7b3f9.jpg)

**Kommentare**

Wenn Sie möchten, können Sie die Kommentare in Ihrer Galerie mit der Komponente [Disqus](https://disqus.com/) verwalten. 

Dazu müssen Sie zuerst ein Konto auf der Website von Disqus erstellen. Wenn Sie Disqus in der Konfiguration von Bootstrap Darkroom aktivieren, geben Sie den Namen Ihrer Disqus-Website im Feld „Disqus shortname“ ein.

![Disqus.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4e8a9f59.jpg)

Beachten Sie: Wenn Sie sich für diese Option entscheiden, werden die Kommentare auf einer Plattform eines Drittanbieters verarbeitet und gespeichert.

**Schlagwortwolke**

Für das Menü „Schlagworte“ Ihrer Galerie können Sie zwischen zwei Arten von Schlagwortwolken wählen.

- Basic: Dieses Format zeigt die Schlagworte in horizontalen Listen an. Es eignet sich weniger, wenn Ihre Galerie nur wenige Schlagworte hat.
    
    ![Ecran tags BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-e75e38d8.jpg)
    
- HTML 5 Canvas: Dieses Format nutzt den ganzen Bildschirm und zeigt die Schlagworte in verschiedenen Richtungen an.
    
    ![Nuage de tags.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-d2452c70.jpg)
    

### Registerkarte 3: Soziale Netzwerke

In der letzten Konfigurations-Registerkarte des Erscheinungsbilds Bootstrap Darkroom legen Sie fest, ob auf der Seite eines Bildes Schaltflächen zum Teilen in sozialen Netzwerken angezeigt werden.

Sie können auswählen, welche sozialen Netzwerke aktiviert werden.

![Paramètres BD.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-0ff897bc.jpg)

Sie können auch festlegen, wie die Schaltflächen zum Teilen angezeigt werden:

- Standardsymbole
    
    ![Boutons réseaux sociaux.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-681a6492.jpg)
    
- Farbige Schaltflächen
    
    ![Boutons couleur.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-67fd263f.jpg)
