# PWG Stuffs: Blöcke in Ihrer Galerie hinzufügen

Das Plugin **PWG Stuffs** bietet verschiedene Möglichkeiten, Blöcke in Ihre Galerie einzufügen. Diese Blöcke ergänzen die bestehenden Seiten. Damit ist es ein sehr umfassendes Plugin, um Ihre Galerie anzupassen.

Es wird hauptsächlich für Folgendes verwendet:

- eine Schlagwortwolke auf der Startseite einfügen
- einen Anmeldebereich auf der Startseite einfügen

---

## Mit PWG Stuffs einen Anmeldebereich auf der Startseite einfügen

Wenn Ihre Galerie zu 100 % privat ist, möchten Sie wahrscheinlich, dass sich Benutzer direkt auf der Startseite anmelden können.

Das ist mit dem Plugin **PWG Stuffs** möglich.

Öffnen Sie in den Einstellungen des Plugins PWG Stuffs den Tab „Einen Block hinzufügen“. Wählen Sie in der Liste „Anmeldung“ und klicken Sie auf „Einen Block hinzufügen“.

![Plugin PWG.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-889c76a3.jpg)

Nun sehen Sie die Konfigurationsoptionen Ihres Blocks. Hier können Sie den Titel Ihres Anmeldeblocks anpassen, festlegen, ob dieser Titel auf der Startseite angezeigt wird, und bestimmen, auf welchen Seiten der Block erscheint.

![Nouveau bloc.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-c04f30b6.jpg)

Speichern Sie. Sie gelangen nun zur Verwaltung der Blöcke.

Wählen Sie beim „Hauptblock“ die Option „Auf der Startseite ausblenden“.

![Gérer les blocs.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-30d37c64.jpg)

Fertig! Ihre Startseite zeigt jetzt ein Anmeldeformular an.

![Formulaire connexion.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-0bf39463.jpg)

Zurück zur Verwaltung der Blöcke: Mit einem Klick auf das rote Kreuz löschen Sie einen hinzugefügten Block, mit einem Klick auf das Werkzeugsymbol bearbeiten Sie seine Einstellungen.

## Mit PWG Stuffs eine Schlagwortwolke auf der Startseite einfügen

Auch um eine Schlagwortwolke auf Ihrer Startseite oder auf einer anderen Seite Ihrer Galerie einzufügen, verwenden Sie das Plugin PWG Stuffs.

Öffnen Sie in den Einstellungen des Plugins PWG Stuffs den Tab „Einen Block hinzufügen“. Wählen Sie in der Liste „Schlagworte“ und klicken Sie dann auf „Einen Block hinzufügen“.

![Bloc tags.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-d714fa7c.jpg)

Nun sehen Sie die Konfigurationsoptionen Ihres Blocks. Hier können Sie den Titel Ihres Schlagwortwolken-Blocks anpassen, festlegen, ob dieser Titel auf der Startseite angezeigt wird, und bestimmen, auf welchen Seiten der Block erscheint.

Ausserdem stehen Ihnen 3 Darstellungsarten zur Auswahl:

- Schlagwortwolke
- Nach Buchstaben gruppieren
- Cumulus-Modus verwenden (dafür muss das Plugin Cumulus Tag Clouds aktiviert sein. Dieses Plugin ist für Kunden von Piwigo Cloud nicht verfügbar)

![Bloc tags config.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-5d29b359.jpg)

Wählen Sie die Option „Schlagwortwolke“ und speichern Sie.

Fertig! Ihre Startseite zeigt jetzt eine Schlagwortwolke an.

![Nuage tags accueil.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4e9e6494.jpg)

Gehen Sie nun zurück zur Verwaltung der Blöcke, bearbeiten Sie den erstellten Block über das Werkzeugsymbol und wählen Sie diesmal die Option „Nach Buchstaben gruppieren“.

Die Schlagworte sind jetzt nach Buchstaben gruppiert und alphabetisch sortiert.

![Tags par lettre.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-8abb5e4c.jpg)

## Weitere Funktionen

Neben dem Anmeldeformular und der Schlagwortwolke können Sie mit dem Plugin PWG Stuffs weitere Blöcke in Ihre Galerie einfügen:

- Persönlicher Block: fügt Text oder HTML-Inhalt Ihrer Wahl ein, zum Beispiel eine Begrüssungsnachricht.
- Letzte Kommentare: zeigt die neuesten Kommentare in der Galerie an
- Zufällige Fotos: zeigt eine festgelegte Anzahl zufälliger Fotos aus der Galerie oder dem aktuellen Album an
- Hervorgehobene Fotos: zeigt die Lieblingsfotos des Benutzers mit dem Status Webmaster an
- Neueste Fotos: zeigt die neuesten Fotos der Galerie oder des aktuellen Albums an (sofern vorhanden)
- Am besten bewertet: zeigt eine festgelegte Anzahl der am besten bewerteten Fotos aus der Galerie oder dem aktuellen Album an
- Am häufigsten angesehen: zeigt eine festgelegte Anzahl der meistbesuchten Fotos aus der Galerie oder dem aktuellen Album an

## Zugriffsberechtigungen für Blöcke

Sie können eine Rechteverwaltung einrichten, um die Anzeige der Blöcke abhängig vom angemeldeten Benutzer anzupassen.

Öffnen Sie dazu in den Einstellungen von PWG Stuffs den Tab „Konfiguration“.

Sie können die Berechtigungen folgendermassen verwalten:

- nach [Benutzerstatus (oder Benutzertyp)](../../benutzer-verwalten/benutzerstatus.md)
- nach [Datenschutzstufe](../../benutzer-verwalten/datenschutzstufen.md)
- nach [Benutzergruppe](../../benutzer-verwalten/benutzergruppen.md)

Angenommen, ein Block soll nur für anonyme Benutzer (die nicht in der Galerie angemeldet sind) angezeigt werden. In diesem Fall aktivieren wir die Rechte nach Benutzertyp.

![Config blocs PWG.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-0a7a7157.jpg)

In den Einstellungen eines Blocks können wir nun die Benutzer auswählen, die diesen Block sehen dürfen. In unserem Beispiel wählen wir nur „Gast“. So sehen nur Benutzer, die nicht angemeldet sind, diesen Block.

![Modifier bloc tags.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-88811045.jpg)

## Module abwechseln

Mit diesem Plugin können Sie die Inhalte Ihrer Galerie sehr weitgehend an die jeweiligen Benutzer anpassen.

Für jedes Modul können Sie nämlich festlegen, auf welcher Art von Seite es angezeigt wird, welcher Benutzertyp es sieht, in welcher Zeile es erscheint und wie breit es ist. Durch geschicktes Kombinieren dieser Einstellungen können Sie zwei Module an derselben Stelle abwechseln lassen.

Zum Beispiel:

- Modul 1 *EDITORIAL* (Anzeigeeinstellungen: Zeile A, 60 %, nur auf der Hauptseite, für alle sichtbar) könnte eine Einführung in Ihre Galerie enthalten.
- Daneben könnte Modul 2 *NEWS* (Anzeigeeinstellungen: Zeile A, 40 %, nur auf der Hauptseite, nur für angemeldete Benutzer sichtbar) neue Besucher dazu anregen, ein Konto zu erstellen, sofern das möglich ist.
- Modul 3 *WELCOME* (Anzeigeeinstellungen: Zeile A, 40 %, nur auf der Hauptseite, nur für angemeldete Benutzer sichtbar) könnte den Benutzernamen und eine Begrüssungsnachricht enthalten.

Beim Aufrufen der Seite sieht der Benutzer oben links das *EDITORIAL* und rechts daneben die *NEWS*. Nach der Anmeldung wird NEWS durch *WELCOME* ersetzt. Sobald er dann die Alben durchstöbert, verschwinden diese Module, um mehr Platz für die Inhalte Ihrer Galerie zu schaffen.
