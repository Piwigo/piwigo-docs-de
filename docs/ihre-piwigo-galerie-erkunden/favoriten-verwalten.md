# Ihre Favoriten verwalten

Wie fügen Sie in Piwigo Fotos zu Ihren Favoriten hinzu und finden sie später leicht wieder? In diesem Artikel fassen wir alle Tipps zusammen.

## Ein Foto in der Galerie zu den Favoriten hinzufügen

Angemeldete Benutzer können in der Piwigo-Galerie ein Foto zu ihren Favoriten hinzufügen, um es später wiederzufinden.

Klicken Sie auf der Seite eines Fotos auf das Symbol „Foto zu den Favoriten hinzufügen“. In den meisten Galerien hat dieses Symbol die Form eines Herzens. Je nach Erscheinungsbild kann es aber anders aussehen.

Sobald ein Foto zu Ihren Favoriten hinzugefügt wurde, ändert das Herzsymbol seine Form. Klicken Sie auf dieses Symbol, um das Foto wieder aus Ihren Favoriten zu entfernen.

## Ihre Favoriten in der Galerie finden

Ihre Favoriten finden Sie auf der Seite „Meine Favoriten“.

Wo sich diese Seite befindet, hängt von Ihrem Erscheinungsbild und den Einstellungen Ihres Menüs ab. In den meisten Fällen erreichen Sie sie über das Menü „Erkunden“ (beim Erscheinungsbild Modus) bzw. „Entdecken“ (beim Erscheinungsbild Bootstrap Darkroom).

![Favoriten finden mit dem Erscheinungsbild Modus](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-a1be4d43.jpg)

Auf der Seite „Meine Favoriten“ können Sie alle Fotos auf einmal aus Ihren Favoriten entfernen, indem Sie auf das entsprechende Symbol klicken.

## Favoriten gesammelt bearbeiten

Im Administrationsbereich können Sie mit der Stapelverarbeitung Änderungen an allen Ihren Favoriten auf einmal vornehmen. Sie finden die Stapelverarbeitung im Administrationsbereich im Menü Fotos > Stapelverarbeitung. Mit dem vordefinierten Filter „Meine Favoriten“ finden Sie Ihre Favoriten dort ganz einfach wieder.

![Filtre favoris.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-3f00c874.jpg)

Anschliessend können Sie unter Ihren Favoriten die zu ändernden Fotos auswählen (oder alle markieren) und die gewünschte Aktion wählen.

Mehr über die Stapelverarbeitung erfahren Sie [in diesem Artikel](../fotos-importieren-und-verwalten/stapelverarbeitung.md).

## Quick Fav: Ein Foto auf der Albumseite zu den Favoriten hinzufügen

Standardmässig ist die Schaltfläche zum Hinzufügen zu den Favoriten nur auf der Seite eines Fotos verfügbar.

Mit dem Plugin **Quick Fav** fügen Sie ein Foto mit einem Klick direkt über sein Vorschaubild hinzu, auf der Albumseite oder auf einer anderen Übersichtsseite.

Ausserdem können Sie damit den gesamten Inhalt eines Albums mit einem Klick zu Ihren Favoriten hinzufügen.

[Mehr über Quick Fav erfahren](alben-in-ihrer-galerie.md#quick-fav-ein-foto-uber-die-albumseite-zu-den-favoriten-hinzufugen)

## User Collections: Favoriten in thematische Sammlungen einordnen

Wenn Sie mehrere thematische Auswahlen erstellen möchten, ist das Plugin User Collections genau das Richtige für Sie!

Damit erstellen Sie Sammlungen, fügen ihnen Dateien hinzu und teilen sie per Link oder E-Mail.

[Mehr über User Collections erfahren](sammlungen-user-collections-plugin.md)
