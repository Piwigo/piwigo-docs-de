## Schlagworte in Ihrer Galerie nutzen

Piwigo-Galerien enthalten standardmässig zwei Menüpunkte für Ihre Schlagworte: „Schlagworte“ und „Verwandte Schlagworte“.

### Verwandte Schlagworte

![Tags.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-80528e77.png)

Auf der Startseite zeigt das Menü die Liste der wichtigsten Schlagworte Ihrer Galerie. Mit einem Klick auf ein Schlagwort sehen Sie alle Fotos, denen dieses Schlagwort zugeordnet ist.

![Tag espagne.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-fca9d8a7.jpg)

Wenn Sie danach erneut das Menü „Verwandte Schlagworte“ öffnen, zeigt es nur noch die Schlagworte der angezeigten Fotos. Klicken Sie nun auf ein weiteres Schlagwort, werden beide Schlagworte kombiniert und die Suche wird verfeinert.

![Combinaison tags.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-6106a105.jpg)

Um ein Schlagwort aus den Suchfiltern zu entfernen, klicken Sie einfach auf das Kreuz neben seiner Bezeichnung.

Wenn Sie auf der Seite eines Albums auf „Verwandte Schlagworte“ klicken, werden nur die Schlagworte angezeigt, die in diesem Album vorkommen.

**Das Menü „Verwandte Schlagworte“ ist also ein sehr nützliches Werkzeug, um Ihre Fotobibliothek zu erkunden und eine Suche Schritt für Schritt zu verfeinern.**

### Schlagworte (Schlagwortwolken)

Das Untermenü „Schlagworte“ unter „Erkunden“ zeigt die Anzahl der Schlagworte in Ihrer Galerie an und öffnet eine Seite, die alle Ihre Schlagworte auflistet.

![Explorer tags.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-03cc8243.jpg)

Die Seite „Schlagworte“ zeigt die Schlagworte als Wortwolke an. Die Grösse jedes Schlagworts entspricht dabei der Anzahl der Fotos, denen es zugeordnet ist.

![Untitled](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-36106dc5.png)

Mit einem Klick auf ein Schlagwort sehen Sie alle Fotos, denen dieses Schlagwort zugeordnet ist.

### Suche nach Schlagwort

Wenn Sie einen Begriff in die Suche der Galerie eingeben und dieser Begriff einem Schlagwort entspricht, sehen Sie den Hinweis „1 Schlagwort gefunden“. Klicken Sie dann auf das Schlagwort, um die zugehörigen Fotos anzuzeigen.

![Recherche tag.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-15bf076b.jpg)

Wenn das Plugin **RV Autocomplete** in Ihrer Galerie aktiviert ist, wird die Liste der Schlagworte bei der Suche sogar per automatischer Vervollständigung angezeigt.

![RV autocomplete.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-f694e0c1.jpg)

Schliesslich können Sie Schlagworte über die Suchfilter mit anderen Suchkriterien kombinieren. Die Filter stehen Ihnen zur Verfügung, sobald Sie eine Suche gestartet haben, oder über das Menü Erkunden > Suchen.

Klicken Sie auf den Filter „Schlagwort“, um Ihrer Suche ein oder mehrere Schlagworte hinzuzufügen.

![Untitled](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-91b1e4f4.png)

[Mehr über die Suchfilter erfahren](ein-foto-in-ihrer-galerie-suchen.md)

## Die Verwaltung von Schlagworten mit Plugins anpassen

### PWG Stuffs: Eine Schlagwortwolke auf der Startseite anzeigen

Möchten Sie auf der Startseite Ihrer Galerie eine Schlagwortwolke anzeigen, wie in [diesem Beispiel](https://demo3.piwigo.com/)?

Dazu aktivieren Sie das Plugin **PWG Stuffs**.

[Mehr erfahren](schlagworte-in-ihrer-galerie/pwg-stuffs-plugin.md)

### Menu Tags: Alle Schlagworte im Menü auflisten

Wie weiter oben auf dieser Seite erklärt, zeigt das Schlagwort-Menü in Ihrer Galerie standardmässig dynamisch die Schlagworte an, die zu den gerade angezeigten Inhalten passen.

Wenn Sie sich also auf der Seite eines Albums befinden, dessen Fotos keine Schlagworte zugeordnet sind, erscheint das Menü „Verwandte Schlagworte“ nicht.

Wenn auf Seiten ohne verwandte Schlagworte ein Menü „Schlagworte“ mit allen verfügbaren Schlagworten Ihrer Galerie erscheinen soll, können Sie das Plugin **Menu Tags** aktivieren.

Dann zeigt das Menü auf der Startseite statt „Verwandte Schlagworte“ ein Menü „Schlagworte“ mit allen Schlagworten Ihrer Galerie an, jeweils in einer Grösse, die ihrer Verwendung entspricht.

### Birthdate: Das Alter eines Motivs auf einem Foto anzeigen

Mit dem Plugin Birthdate können Sie einem Schlagwort ein Geburtsdatum zuordnen. So lässt sich anzeigen, wie alt ein Motiv auf einem Foto zum Zeitpunkt der Aufnahme war.

Diese Funktion wird oft für Fotos von Personen genutzt, vor allem von Kindern. Angenommen, ich habe eine Reihe von Fotos eines Kindes namens John. Mit dem Plugin Birthdate ordne ich dem Schlagwort „John“ sein Geburtsdatum zu.

In der Galerie wird dann neben jedem Foto von John angezeigt, wie alt er war, als das Foto aufgenommen wurde (sogar auf die Stunde genau!).

Diese Funktion kann auch in anderen Fällen nützlich sein:

- das Wachstum einer Pflanze ab dem Tag der Pflanzung verfolgen
- die Entwicklung eines Gebäudes ab dem Baudatum verfolgen
- …

### Tag Groups: Schlagwortgruppen erstellen

Standardmässig befinden sich alle Schlagworte auf derselben Ebene, anders als Alben, die in einer Baumstruktur angeordnet sind.

Mit dem Plugin **Tag Groups** können Sie jedoch eine Baumstruktur mit einer Ebene für Schlagworte erstellen.

!!! info "Info"
    Wenn Sie Kunde von Piwigo Cloud sind, ist dieses Plugin erst ab dem Enterprise-Tarif verfügbar.

Mit diesem Plugin erstellen Sie Schlagwortgruppen: zum Beispiel eine Gruppe „Farbe“ mit einem Schlagwort pro Farbe oder eine Gruppe „Stadt“ mit einem Schlagwort pro Stadt.

Statt als Schlagwortwolke auf der Seite „Schlagworte“ Ihrer Galerie können die Schlagworte dann nach Gruppen sortiert angezeigt werden.

![Untitled](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-87aed4ac.png)

Mit diesem Plugin können Sie in Ihrer Galerie ausserdem Filter nach Schlagwortgruppen einrichten.

![Untitled](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-8b84279a.png)

**Wie erstelle ich eine Schlagwortgruppe?**

Um eine Schlagwortgruppe „color“ zu erstellen, legen Sie einfach ein Schlagwort „color:blue“, ein Schlagwort „color:red“ usw. an.

Auf dieselbe Weise erstellen Sie eine Gruppe „city“, indem Sie ein Schlagwort „city:paris“, ein Schlagwort „city:london“ usw. anlegen.

**Wie zeige ich Schlagworte nach Gruppen an?**

Die Anzeige nach Gruppen ersetzt die Schlagwortwolke auf der Seite „Schlagworte“ Ihrer Galerie.

Um die Schlagworte nach Gruppen anzuzeigen, klicken Sie auf der Seite „Schlagworte“ oben rechts auf die Schaltfläche „Schlagwortgruppen anzeigen“.

![Montrer groupes de tags.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-49e461c0.jpg)

Die Seite „Schlagworte“ kann die Schlagworte auch standardmässig nach Gruppen anzeigen.

Wenn Sie Kunde eines Piwigo-Cloud-Tarifs sind, wenden Sie sich an den Support, um diese Option aktivieren zu lassen.

Wenn Sie eine selbst gehostete Piwigo-Galerie nutzen, können Sie die Option aktivieren, indem Sie die lokale Konfiguration mit LocalFiles Editor bearbeiten und die folgende Einstellung verwenden.

```php
$conf['tags_default_display_mode'] = 'groups';
```

**Wie aktiviere ich Filter mit mehreren Kriterien nach Schlagwortgruppen?**

Wenn Sie Kunde eines Piwigo-Cloud-Tarifs sind, wenden Sie sich an den Support, um diese Option aktivieren zu lassen.

Wenn Sie eine selbst gehostete Piwigo-Galerie nutzen, können Sie die Option aktivieren, indem Sie die lokale Konfiguration mit LocalFiles Editor bearbeiten und die folgenden Einstellungen verwenden.

```php
$conf['tag_groups_index_filters'] = true;
$conf['tag_groups_dynamic_filters'] = true;
```

Mehr über Schlagwortgruppen erfahren Sie hier:

### Schlagworten mit Colored Tags Farben zuweisen

Wenn Sie das Plugin Colored Tags aktivieren, können Sie Schlagworten eine Farbe zuweisen.

Sobald das Plugin aktiviert ist, legen Sie in seiner Konfiguration eine Liste von Farben fest, entweder per Hex-Code oder über den Farbkreis.

![Couleurs de tags.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-57357e72.jpg)

Um die Farbe eines Schlagworts zu ändern, öffnen Sie im Administrationsbereich das Menü Fotos > Schlagworte und wechseln in den Auswahlmodus. Dort können Sie einem oder mehreren Schlagworten eine Farbe zuweisen.

![Tags avec couleurs.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-3eb03a55.jpg)

Die Farben der Schlagworte sind in Ihrer Galerie im Menü „Verwandte Schlagworte“ und auf der Seite „Schlagworte“ zu sehen.

![Tags colorés.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-a95d65d5.jpg)

![Affichage tags couleur.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-38ee7cfb.jpg)

### Tag To Keyword: „Tag“ in „Keyword“ umbenennen

Manche Benutzer mögen den Begriff „Tag“ nicht und bevorzugen „Keyword“.

Deshalb gibt es das Plugin „Tag To Keyword“, das nach der Aktivierung das Wort „Tag“ durch „Keyword“ ersetzt.
