# Alben und Unteralben: Einführung

## Kurz gesagt

Alben bilden das Herzstück der Struktur Ihrer Fotobibliothek. 

Mit Piwigo können Sie Ihre Dateien in Alben und Unteralben einordnen.

Jede Datei muss sich in mindestens einem Album befinden. Mit Alben können Sie:

- festlegen, wie Ihre Inhalte in Ihrer Galerie angezeigt werden
- eine Datei dank einer logischen Baumstruktur leicht wiederfinden
- die Sichtbarkeit von Inhalten je nach Benutzerprofil steuern

Es ist daher wichtig zu verstehen, wie Alben funktionieren und welche Optionen es dafür gibt.

## Die Baumstruktur von Alben und Unteralben

Die Alben sind in einer Baumstruktur organisiert, wie die Dateien auf Ihrem Computer.

Die Alben ganz oben im Baum heissen „Stammalben“. Unteralben werden manchmal auch „untergeordnete Alben“ genannt.

Ein Album kann beliebig viele Unteralben enthalten, die wiederum eigene Unteralben haben können, und so weiter…

Beispiel für eine Baumstruktur:

- Tiere
    - Säugetiere
        - Katzenartige
            - Katzen
            - Tiger
            - Löwen
        - Rinder
            - Kühe
            - Büffel

Im obigen Beispiel wird das Album „Büffel“ im Administrationsbereich von Piwigo meist in der Form „Tiere / Rinder / Büffel“ angezeigt. So finden Sie sich leicht zurecht.

In Ihrer Web-Galerie zeigt Piwigo die Liste der Stammalben an. Hat ein Album Unteralben, sehen Sie diese, wenn Sie darauf klicken, und so weiter. Ein Beispiel dafür finden Sie in [dieser Demo-Galerie](https://demo1.piwigo.com/).

Bei jedem Stammalbum wird die Anzahl der enthaltenen Unteralben angezeigt.

Hat ein Album keine Unteralben, wird die Anzahl der Fotos angezeigt. Wenn Sie auf ein Album klicken, sehen Sie also entweder die Liste seiner Unteralben oder direkt eine Liste von Fotos.
