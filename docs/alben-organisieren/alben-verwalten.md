# Alben verwalten

## Die Albenliste im Administrationsbereich anzeigen

Um Ihre Alben zu erstellen, zu bearbeiten, zu löschen und neu zu ordnen, öffnen Sie den Administrationsbereich von Piwigo und wählen Sie im Menü links Alben > Verwaltung.

Der erste Tab listet Ihre Alben auf und bietet Ihnen zahlreiche Funktionen.

- Sie sehen Ihre Alben als Baumstruktur. Übergeordnete Alben, die Unteralben enthalten, erkennen Sie leicht an ihrem baumförmigen Symbol.
- Mit einem Klick auf das nach unten zeigende Pfeilsymbol klappen Sie einen Zweig auf oder zu.
- Bei jedem Album zeigen Beschriftungen die Anzahl der enthaltenen Dateien, die Anzahl der Unteralben und die Gesamtzahl der Dateien (einschliesslich der Unteralben) an.
- Um die Anzeigereihenfolge der Alben zu ändern, wählen Sie einfach das gewünschte Album aus und verschieben es per Drag-and-drop.
- Auf dieselbe Weise können Sie ein Album in ein anderes verschieben oder ein Unteralbum auf die oberste Ebene holen.

![Ordre albums.gif](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-6b852a22.gif)

Über die Suche oben rechts finden Sie ein Album schnell anhand seines Namens.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-a9be794c.png)

## Die Anzeigereihenfolge Ihrer Alben ändern

Wie oben beschrieben, können Sie die Reihenfolge der Alben in der Liste ganz nach Wunsch ändern, indem Sie sie einfach per Drag-and-drop verschieben. Diese Reihenfolge wird sofort in Ihrer Galerie übernommen.

Sie können auch eine automatische Sortierreihenfolge anwenden.

Klicken Sie dazu oben in der Liste auf die Schaltfläche „Automatische Sortierreihenfolge“. Es öffnet sich ein Fenster mit allen verfügbaren Optionen zum Sortieren Ihrer Alben.

Sie können wählen, ob Sie die gewünschte Sortierreihenfolge:

- nur auf die Stammalben anwenden
- auf den gesamten Baum (einschliesslich der Unteralben) anwenden

![Ordre automatique.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4fb855fb.jpg)

Um die Sortierreihenfolge der Unteralben innerhalb eines bestimmten Albums zu ändern, klicken Sie in der Liste beim gewünschten Album auf das Symbol „Automatische Sortierreihenfolge“.

![Icone album.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-c0ed726f.jpg)

Das Fenster zur Auswahl der Sortierreihenfolge öffnet sich. Wenn Sie auf „Auf direkte Unteralben anwenden“ klicken, wird die gewählte Reihenfolge nur auf das ausgewählte Album angewendet.

![Ordre animaux.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-07c3e71f.jpg)

## Dateien in ein Album importieren

Direkt aus der Liste können Sie Dateien in ein bestimmtes Album importieren. Klicken Sie dazu rechts auf das Symbol „Fotos hinzufügen“.

![Ajouter photos.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-dd321001.jpg)

Sie gelangen dann zur Seite für den [Datei-Import](../fotos-importieren-und-verwalten/fotos-in-piwigo-importieren.md), auf der das ausgewählte Album bereits eingestellt ist.

## Den Inhalt eines Albums ansehen

Um den Inhalt eines Albums anzusehen, klicken Sie auf das Symbol „Galerie ansehen“. Es öffnet sich eine neue Seite mit der Seite des gewählten Albums in Ihrer Galerie.

![Visiter galerie.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-e9c7ea83.jpg)

## Ein Album löschen

Um ein Album zu löschen, klicken Sie auf das Symbol „Album löschen“.

## Permalinks von Alben bearbeiten

Mit Permalinks geben Sie einem Album eine aussagekräftigere URL als die, die Piwigo standardmässig erstellt.

Wenn Sie Ihr erstes Album erstellen, sieht seine URL standardmässig so aus: https://mysite.com/piwigo/index.php?/category/1

Heisst Ihr Album „Animals“, können Sie mit einem Permalink seine URL so ändern, dass sie so aussieht: https://mysite.com/piwigo/index.php?/category/animals

Um Permalinks zu erstellen und zu verwalten, öffnen Sie im Administrationsbereich das Menü Alben > Verwaltung und dort den Tab „Permalinks“.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-d7cb94c0.png)

Um einen neuen Link hinzuzufügen, klicken Sie auf „Hinzufügen/ Entfernen eines Permalinks“.

Wählen Sie das Album aus, dessen Link Sie ändern möchten, und geben Sie den Text ein, der in der URL erscheinen soll. Leerzeichen und Sonderzeichen (Akzente usw.) sind nicht erlaubt.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-3ee90fc1.png)

Aktivieren Sie die Option „Speichere in der Permalink-History“, wenn Sie die Anzahl der Besuche verfolgen möchten, die dieser Permalink Ihrem Album bringt, oder wenn Sie einfach festhalten möchten, dass es ihn gab, falls Sie den Link später löschen. Klicken Sie zum Speichern auf „Absenden“.

Nach dem Erstellen finden Sie Ihre Permalinks in der Liste.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4853c807.png)

Um einen Permalink zu entfernen, klicken Sie erneut auf „Hinzufügen/ Entfernen eines Permalinks“. Wählen Sie den Link aus, den Sie löschen möchten, und klicken Sie auf „Absenden“.

Der gelöschte Link erscheint nun in der Liste „Permalink-History“.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2ba37b04.png)
