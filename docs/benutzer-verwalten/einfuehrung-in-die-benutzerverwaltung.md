# Benutzer: Einführung

## Benutzer in Piwigo

Um Piwigo richtig zu nutzen, müssen Sie verstehen, was ein Benutzer ist.

In Piwigo ist ein Benutzer jede Person, die Ihre Web-Galerie besucht.

Ein Benutzer kann also sein:

- Anonym: Wenn Ihre Galerie öffentliche Alben enthält, kann ein Benutzer deren Inhalt ansehen, ohne registriert zu sein. Er muss weder ein Konto erstellen noch sich anmelden. Er hat den Status **Gast**. [Mehr erfahren](benutzerstatus.md)
- Registriert: Ein registrierter Benutzer hat ein Benutzerkonto bei Piwigo. Sobald er bei Piwigo angemeldet ist, sieht er individuelle Inhalte, die sich von dem unterscheiden können, was ein anderer Benutzer sieht. Was ein Benutzer in Piwigo sieht, hängt von mehreren Kriterien ab:
    - Sein Status (Besucher, Administrator, Webmaster): [mehr erfahren](benutzerstatus.md)
    - Die Alben, die er sehen darf: [mehr erfahren](benutzer-erstellen-und-verwalten.md)
    - Die Gruppe(n), in denen er Mitglied ist: [mehr erfahren](benutzergruppen.md)
    - Seine Datenschutzstufe: [mehr erfahren](datenschutzstufen.md)
    - Seine Einstellungen: [mehr erfahren](benutzer-erstellen-und-verwalten.md)

## Benutzer: Konfigurationsoptionen

Im Menü Optionen > Konfiguration wirken sich einige allgemeine Optionen auf die Benutzerverwaltung aus.

![Permissions utilisateur.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-18d71862.jpg)

- Neuregistrierung von Benutzern erlauben

Wenn Sie diese Option aktivieren, können Benutzer ihr Konto in Ihrer Galerie selbst erstellen. Sie können die Registrierung von der Freigabe durch einen Administrator abhängig machen.

Wenn Sie diese Option deaktivieren, müssen Benutzer von einem Administrator im Administrationsbereich von Piwigo angelegt werden.

- Eigene Benutzer-Anpassungen erlauben

Wenn Sie diese Option aktivieren, können Benutzer ihre Einstellungen in ihrem Konto in der Galerie selbst ändern, indem sie auf das Menü „Anpassen“ klicken.

Einstellungen sind Anzeigeoptionen: Erscheinungsbild, Sprache, Anzahl der Fotos pro Seite… [Mehr über Einstellungen](benutzer-erstellen-und-verwalten.md)

Wenn Sie diese Option deaktivieren, können Benutzer ihre Einstellungen nicht ändern.
