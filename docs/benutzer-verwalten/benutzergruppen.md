# Benutzergruppen

Bei vielen Benutzern wird es schnell mühsam, für jeden einzelnen Einstellungen und Zugriffsrechte zu verwalten.

Genau dafür gibt es Benutzergruppen.

Mit Gruppen legen Sie die Zugriffsrechte und Einstellungen für ein bestimmtes Benutzerprofil ein für alle Mal fest.

Wenn Sie danach einen neuen Benutzer erstellen, ordnen Sie ihn einfach der oder den passenden Gruppen zu.

Und wenn Sie ein privates Album erstellen, müssen Sie nicht alle Benutzer auflisten, die darauf Zugriff haben, sondern nur die Gruppen.

## Eine neue Benutzergruppe erstellen

Die Liste der Benutzergruppen finden Sie im Administrationsbereich im Menü Benutzer > Gruppen.

Dort werden die Benutzergruppen als Kacheln angezeigt. Sie können sie bearbeiten und neue Gruppen erstellen.

![Liste des groupes.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-57de41a3.jpg)

Um eine Gruppe zu erstellen, klicken Sie auf der Seite zur Gruppenverwaltung auf „Gruppe hinzufügen“.

Geben Sie Ihrer Gruppe dann einen Namen: Die Gruppe wird erstellt.

Wenn Sie mit der Maus über Ihre Gruppe fahren, stehen Ihnen zwei Möglichkeiten zur Verfügung:

- Mitglieder verwalten
- Zugriffsrechte verwalten

## Benutzer einer Gruppe zuordnen

Um auf der Seite „Gruppen“ Benutzer zu einer Gruppe hinzuzufügen, fahren Sie mit der Maus über die Gruppe und klicken auf „Benutzer verwalten“.

Es öffnet sich ein Fenster, in dem Sie die Benutzer auswählen, die Sie dieser Gruppe zuordnen möchten.

![Ajouter utilisateur groupe.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-c09bfa90.jpg)

Um einen Benutzer zuzuordnen, wählen Sie ihn in der Liste aus und klicken auf das orangefarbene Symbol.

Wiederholen Sie das so oft wie nötig. Die Liste der Benutzer in der Gruppe wird unten im Fenster angezeigt. Falls Sie sich vertan haben, können Sie Benutzer wieder aus der Gruppe entfernen.

Wenn Ihnen das lieber ist, können Sie Benutzer auch über die Benutzerliste einer Gruppe zuordnen. So ordnen Sie jeden Benutzer einzeln einer oder mehreren Gruppen zu oder ordnen im Auswahlmodus mehrere Benutzer auf einmal Gruppen zu.

Mehr dazu erfahren Sie [im Artikel zur Benutzerverwaltung](benutzer-erstellen-und-verwalten.md).

## Zugriffsrechte einer Gruppe verwalten

Um auf der Seite „Gruppen“ festzulegen, auf welche Alben eine Gruppe Zugriff hat, fahren Sie mit der Maus über die Gruppe und klicken auf „Zugriffsverwaltung“.

Im folgenden Fenster sehen Sie links die privaten Alben, auf die diese Gruppe Zugriff hat, und rechts die Alben, auf die sie keinen Zugriff hat. Wenn eine Gruppe neu erstellt wird, sind standardmässig alle Alben gesperrt.

Damit die Mitglieder einer Gruppe Alben sehen können, verschieben Sie die gesperrten Alben einfach mit den Pfeilen in die Spalte „Erlaubt“.

![Permissions albums groupes.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-78070892.jpg)

Die berechtigten Gruppen für ein bestimmtes Album können Sie auch über die Albenliste und die Albumbearbeitung festlegen. Beim Bearbeiten eines Albums legen Sie im Tab „Zugriffsrechte“ fest, welche Gruppen das Album sehen dürfen.

[Mehr über Zugriffsrechte auf Alben](../alben-organisieren/zugriffsrechte-und-sichtbarkeit-von-alben.md)

![Permission groupes albums.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-e71fcb9a.jpg)

## Eine Gruppe umbenennen

Um eine Benutzergruppe in der Gruppenliste umzubenennen, klicken Sie auf das Stift-Symbol neben ihrem Namen, ändern den Namen und klicken auf das orangefarbene Symbol, um die Änderung zu speichern.

![Modifier nom groupe.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-e7150b98.jpg)

## Eine Gruppe duplizieren

Um beim Erstellen einer Benutzergruppe Zeit zu sparen, können Sie eine bestehende Gruppe duplizieren. Klicken Sie dazu in der Gruppenliste auf die 3 Punkte oben rechts in einer Gruppe und dann auf „Duplikat“.

![Options pour groupe.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-9d2c1eaf.jpg)

Daraufhin wird eine Kopie dieser Gruppe erstellt: Sie müssen sie nur noch umbenennen und bearbeiten.

## Eine Gruppe löschen

Um eine Gruppe in der Gruppenliste zu löschen, klicken Sie auf die 3 Punkte oben rechts in der Gruppe und dann auf „Löschen“.

Um mehrere Gruppen zu löschen, aktivieren Sie den Auswahlmodus mit einem Klick auf die Schaltfläche „Auswahlmodus“ oben rechts auf dem Bildschirm.

Markieren Sie dann die Gruppen, die Sie löschen möchten, und klicken Sie auf „Löschen“.

![Mode sélection groupes.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2c918c1c.jpg)

## Eine Standardgruppe für neue Benutzer festlegen

Sie können eine Gruppe festlegen, der alle neu erstellten Benutzer automatisch zugeordnet werden.

Klicken Sie dazu in der Gruppenliste auf die 3 Punkte oben rechts in einer Gruppe und dann auf „Als Gruppe für neue Benutzer festlegen“.

## Benutzergruppen zusammenführen

In der Gruppenliste können Sie mehrere Gruppen zu einer zusammenführen.

Klicken Sie dazu auf die Schaltfläche „Auswahlmodus“ oben rechts auf dem Bildschirm.

Markieren Sie dann die Gruppen, die Sie zusammenführen möchten.

![Fusion groupes.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2e06b614.jpg)

In der Auswahlliste rechts wählen Sie, welche Gruppe erhalten bleibt: Alle Benutzer der anderen Gruppen werden der Zielgruppe hinzugefügt, und alle anderen Gruppen werden gelöscht.
