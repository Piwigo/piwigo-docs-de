# Einführung: Piwigo in 2 Minuten verstehen

## Was ist Piwigo?

### Piwigo kurz vorgestellt

Piwigo ist eine Online-Software zur Verwaltung von Fotobibliotheken. Sie ist im Web und als mobile App verfügbar. Mit Piwigo können Sie Fotos, Videos und andere Dokumente (zum Beispiel PDFs) importieren, organisieren, sortieren und öffentlich oder privat teilen. 

Piwigo wurde ursprünglich für die Verwaltung von Fotos entwickelt und ist dafür optimiert. Deshalb ist in dieser Dokumentation und in der Software meistens von Fotos die Rede. Was für Fotos gilt, gilt aber auch für alle anderen Bildtypen und in den meisten Fällen auch für andere Dateitypen. 

### Warum Piwigo verwenden?

Viele Organisationen und Privatpersonen nutzen Piwigo, um ihre visuellen Ressourcen zu speichern, zu sortieren und zu teilen: Fotos, Videos, Kommunikationsmaterial, Broschüren…

Die Vorteile sind zahlreich:

- Piwigo ist sicherer und zuverlässiger als herkömmliche Lösungen (Server mit geteilten Dateien, externe Festplatte, USB-Sticks…) und eignet sich viel besser für die Arbeit aus der Ferne.
- Mit Piwigo sortieren Sie Dateien einfach und intuitiv. So verlieren Sie weniger Zeit mit der Suche nach den benötigten Dateien.
- Piwigo schützt den Zugriff auf Ihre Daten: Dank der erweiterten Verwaltung von Zugriffsrechten legen Sie ganz einfach fest, wer auf welche Datei zugreifen darf.
- Mit Piwigo teilen Sie eine Datei oder eine Auswahl von Dateien sicher und schnell über einen einfachen Link. So vermeiden Sie E-Mails mit Anhängen, Duplikate und Fehlerquellen…
- Mit Piwigo erstellen Sie eine echte Website, öffentlich oder privat, um Ihre Fotos zu speichern und zu präsentieren. Diese Bibliothek lässt sich an Ihre Farben anpassen.

Mehr dazu erfahren Sie [auf unserer Website](https://de.piwigo.org/).

# So funktioniert Piwigo

Piwigo ist eine Online-Software, die Sie einfach über einen Webbrowser nutzen.

Piwigo besteht aus zwei Hauptbereichen:

- dem Administrationsbereich
- der Galerie

Diese Begriffe sind wichtig, um den Rest der Dokumentation zu verstehen.

## Der Administrationsbereich

Der Administrationsbereich ist das Backoffice von Piwigo: Hier fügen Sie Dateien hinzu, erstellen Alben, organisieren, bearbeiten, verschieben und löschen Elemente, rufen die Einstellungen auf... Nur Benutzer mit dem Status Administrator oder Webmaster können sich im Administrationsbereich anmelden.

## Die Galerie

Die Galerie ist das Aushängeschild von Piwigo: eine Website, auf der man alle Inhalte Ihrer Fotobibliothek ansehen kann. Sie können diese Inhalte allen Besuchern der Website zugänglich machen oder sie nur berechtigten Benutzern vorbehalten. [Entdecken Sie unsere Demos](https://piwigo.com/demo), um Beispiele für Piwigo-Galerien zu sehen.

## Die Benutzer

Wenn Sie Ihr Konto bei Piwigo cloud erstellen, haben Sie alle Rechte: Ihr Status ist standardmässig „Webmaster“.

Danach können Sie neue Benutzer erstellen:

- Administratoren: Sie haben Zugriff auf den Administrationsbereich von Piwigo, um Alben zu erstellen, Fotos hinzuzufügen…
- Besucher: Sie haben nur Zugriff auf Ihre Piwigo-Galerie, um Dateien zu suchen, anzusehen und herunterzuladen.

[Mehr über die Benutzer erfahren](../benutzer-verwalten/index.md)

## Die Alben

Um Dateien zu Ihrem Piwigo hinzuzufügen, müssen Sie zuerst ein Album erstellen.

Die Dateien werden in Alben und Unteralben organisiert, ähnlich wie die Ordner auf Ihrem Computer. Die Baumstruktur kann beliebig tief sein.

Das Besondere daran: Eine Datei kann sich gleichzeitig in mehreren Alben befinden, ohne dass Duplikate entstehen!

Mit Ihren Alben sortieren Sie Ihre Dateien in sinnvolle Ordner. Ausserdem eignen sie sich gut, um die Zugriffsrechte der Benutzer zu verwalten.

Sie können nämlich festlegen, dass bestimmte Alben nur für bestimmte Benutzer sichtbar sind. Wenn Sie viele Benutzer haben, können Sie Benutzergruppen erstellen, um die Verwaltung zu vereinfachen: zum Beispiel eine Gruppe für jede Abteilung Ihres Unternehmens oder für jede Tochtergesellschaft. 

[Mehr über die Alben erfahren](../alben-organisieren/index.md)

## Die Schlagworte

Zusätzlich zu den Alben können Sie Ihre Fotos in Piwigo mit Schlagworten sortieren.

Schlagworte sind Stichwörter, die Sie mit Dateien verknüpfen können. Eine Datei kann mit beliebig vielen Schlagworten verknüpft werden. 

In Ihrer Galerie können Benutzer Dateien nach Schlagworten suchen, auch mit einer Kombination aus mehreren Schlagworten.

Sie können die Suche nach Schlagworten [in dieser Demo-Galerie](https://demo3.piwigo.com/) ausprobieren.

## Die Plugins

Um Piwigo um Optionen und Funktionen zu erweitern, steht Ihnen eine Bibliothek mit über hundert Plugins zur Verfügung.

Ein Plugin ist eine Erweiterung, die Ihrer Piwigo-Galerie Code hinzufügt. So wird Piwigo nicht mit Funktionen überladen, die nicht jeder braucht.

In dieser Dokumentation lernen Sie viele Plugins kennen, die für Sie nützlich sein könnten. 

Wenn Sie Kunde von Piwigo cloud sind, können Sie auch dem Support Ihre Bedürfnisse schildern: Wir sagen Ihnen, welche Plugins am besten dazu passen.

Hier einige Beispiele für sehr beliebte Plugins:

- **Batch Downloader**: Mit diesem Plugin können die Benutzer Ihrer Galerie eine Auswahl von Fotos als eine oder mehrere .zip-Dateien herunterladen
- **Download by size**: Mit diesem Plugin können die Benutzer Ihrer Galerie wählen, in welcher Grösse sie eine Datei herunterladen
- **User Collections**: Mit diesem Plugin können die Benutzer Ihrer Galerie Sammlungen bzw. Auswahlen von Fotos erstellen, um sie leicht wiederzufinden oder zu teilen
- **Advanced Menu Manager**: Mit diesem Plugin passen Sie die Menüs Ihrer Galerie und deren Aussehen an
- **Community:** Mit diesem Plugin können Benutzer Ihrer Galerie, die keine Administratoren sind, Dateien zu Ihrer Piwigo-Galerie hinzufügen. Sie werden dann Mitwirkende genannt.

Und es gibt noch Dutzende mehr!

# Piwigo-Abonnements

Um Piwigo zu nutzen, können Sie ein Konto auf der Website von [Piwigo Cloud](https://de.piwigo.org/piwigo-bekommen) erstellen: Sie erhalten eine kostenlose Testphase von 30 Tagen, um die Software auszuprobieren.

Danach müssen Sie ein Abonnement wählen, um Piwigo weiter zu nutzen.

Wir bieten 4 Tarife an, die jeweils auf die Bedürfnisse unterschiedlicher Kundentypen zugeschnitten sind:

- Einen Pro-Tarif für selbstständige und freiberufliche Fotografen
- Einen Team-Tarif für kleine Teams
- Einen Enterprise-Tarif für mittelgrosse Unternehmen und Organisationen
- Einen VIP-Tarif für grössere Unternehmen und Organisationen mit den höchsten Ansprüchen

[Tarife ansehen](https://de.piwigo.com/preise)

Jeder Tarif hat bestimmte Beschränkungen:

- Anzahl der Administratoren
- Speicherplatz

Ausserdem sind einige Funktionen und Plugins nur in bestimmten Tarifen verfügbar. Plugins sind Erweiterungen, mit denen Sie Piwigo um Funktionen ergänzen können.

[Verfügbare Plugins je Tarif ansehen](https://app.notion.com/p/List-of-plugins-and-features-by-plan-2024-cb81ecd2a398442d9e5056cd2a380588?pvs=21)

Schliesslich können Sie zusätzlichen Speicherplatz bestellen.

# Piwigo selbst hosten

Piwigo ist eine freie Open-Source-Software. Das bedeutet, dass der Code der Software offen und für alle zugänglich ist. Jeder kann Piwigo herunterladen und auf dem eigenen Webserver installieren. Wenn Sie Programmierkenntnisse haben, können Sie sogar lernen, eigene Plugins zu entwickeln und Piwigo an Ihre speziellen Bedürfnisse anzupassen. 

Wenn Sie den Wunsch und die nötigen Kenntnisse haben, um Ihr eigenes Piwigo zu installieren, zu hosten und zu warten, können Sie die neueste Version auf der Website [piwigo.org](https://de.piwigo.org/) herunterladen.

In diesem Fall ist die Nutzung von Piwigo völlig kostenlos. 

Wenn Sie sich dafür entscheiden, sollten Sie die Folgen kennen:

- Sie haben keinen Zugang zum Kundensupport, sondern nur zur Dokumentation und zur Unterstützung durch die Community;
- Sie sind allein für Updates und Backups verantwortlich;
- Wenn Sie die Quelldateien Ihres Piwigo verändern, werden Ihre Änderungen bei einem Update „überschrieben“;

Wenn Sie eine selbst gehostete Galerie nutzen und trotzdem von der Unterstützung unseres Teams profitieren möchten, können Sie unseren [Wartungsvertrag](https://de.piwigo.com/preise?plan=self_hosted) abschliessen.

Mehr über das Selbst-Hosten erfahren Sie [hier](../piwigo-selbst-hosten/index.md).
