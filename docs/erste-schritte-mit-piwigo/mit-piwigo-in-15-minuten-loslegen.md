# Mit Piwigo in 15 Minuten loslegen

Und wenn Sie lieber lesen, folgen Sie der Anleitung unten.

## Ihr Konto erstellen

Wenn Sie hier angekommen sind, haben Sie Piwigo vielleicht schon auf Ihrem Server installiert oder Ihr Konto bei Piwigo Cloud erstellt.

Wenn Sie aber ein Konto bei Piwigo Cloud erstellen möchten, [besuchen Sie diese Seite](https://de.piwigo.com/anmelden).

Für Ihr Konto brauchen wir nur 3 Angaben:

- Ihre E-Mail-Adresse: Wählen Sie eine E-Mail-Adresse, auf die Sie Zugriff haben. An diese Adresse erhalten Sie wichtige Informationen zu Ihrem Konto. Sie können sie später natürlich ändern.
- Benutzername: Wählen Sie ihn sorgfältig! Er ist nicht nur Ihr Anmeldename für Piwigo, sondern auch der erste Teil der Webadresse Ihrer Galerie! Alle Konten bei [Piwigo Cloud](https://de.piwigo.org/piwigo-bekommen) haben nämlich eine Webadresse nach dem Muster „benutzername.piwigo.com“. Wenn Sie möchten, können Sie Ihre Galerie später mit einem eigenen Domainnamen verbinden.
- Ihr Passwort: Wählen Sie ein sicheres Passwort. Merken Sie es sich gut, wir können es Ihnen nicht mitteilen (falls Sie es doch vergessen, keine Panik: Sie können jederzeit ein neues anfordern).

![Création compte Piwigo.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-5b4cf5e4.jpg)

Wenige Sekunden später ist Ihr Konto erstellt! Anschliessend werden Sie gebeten, sich anzumelden.

![Docpiwigoen.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-f7747338.jpg)

Danach können Sie angeben, ob Sie ein Unternehmen oder eine Privatperson sind. Sie können das auch später beantworten, im Moment spielt es keine Rolle. 

Sie können sofort damit beginnen, Fotos zu Ihrem Piwigo hinzuzufügen. Klicken Sie auf die Schaltfläche, um zum Formular zum Hochladen von Fotos zu gelangen. Sie können das auch später erledigen. 

![Empty gallery.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-ab089169.jpg)

## Ihre ersten Fotos hinzufügen

Wir schlagen Ihnen nun vor, die ersten Fotos zu Ihrem Konto hinzuzufügen. Wir empfehlen das, denn so gelingt der Einstieg in Piwigo am besten. Klicken Sie auf die Schaltfläche: Sie gelangen dann zum Formular zum Hochladen von Fotos.

![Welcome screen.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-d8f56d6c.jpg)

Wie auf dem Bildschirm angegeben, müssen Sie zuerst ein Album erstellen, in dem Ihre Fotos abgelegt werden. Sobald Sie dieses erste Album erstellt haben, wählen Sie einige Dateien aus und fügen Sie sie hinzu, entweder mit der Schaltfläche „Fotos hinzufügen“ oder einfach per Drag-and-drop von Ihrem Computer. Die Liste der ausgewählten Dateien erscheint dann auf dem Bildschirm.

![First album.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-de598917.jpg)

Klicken Sie auf „Upload starten“: Fertig, Ihre Fotos wurden zu Piwigo hochgeladen!

![First upload.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-747c9707.jpg)

Um zu sehen, wie das in Ihrer Galerie aussieht, klicken Sie oben links auf dem Bildschirm auf die Schaltfläche „Galerie“. Nun sehen Sie Ihre Galerie mit ihrem Standard-Layout.

![Home page.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-02d21e08.jpg)

[Mehr über das Importieren von Fotos erfahren](../fotos-importieren-und-verwalten/index.md)

## Ihr erstes Album privat machen

Kehren wir in den Administrationsbereich zurück: Klicken Sie dazu oben rechts in Ihrer Galerie auf den Link „Administration“.

Standardmässig ist das erste Album, das Sie erstellt haben, öffentlich: Jeder, der einen Link zu Ihrer Galerie hat, kann diese Dateien also sehen.

Wir machen dieses Album nun privat, damit nur Sie es sehen können. 

Klicken Sie im Menü links auf Alben > Verwaltung. Sie gelangen zur Liste Ihrer Alben.

![Manage album.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-b0a4d907.jpg)

Fahren Sie mit der Maus über Ihr erstes Album und klicken Sie auf „Album bearbeiten“.

![Edit album.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-b1fd0ebf.jpg)

Nun stehen Ihnen mehrere Optionen zur Verfügung, um Ihr Album zu bearbeiten.

![Edit album page.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-040876fb.jpg)

Klicken Sie auf die Registerkarte „Zugriffsrechte“.

![Album permissions.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-a0005410.jpg)

Mit der entsprechenden Option können Sie Ihr Album nun auf privat stellen. So können nur Benutzer mit einem Konto in Ihrem Piwigo die Fotos dieses Albums in Ihrer Galerie sehen!

Denken Sie daran, sich selbst die Berechtigung zu geben, dieses Album zu sehen.

![Permissions private.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-5a9205f0.jpg)

Klicken Sie auf „Einstellungen sichern“, um Ihre Änderungen zu bestätigen.

[Mehr über Alben erfahren](../alben-organisieren/index.md)

## Das Erscheinungsbild Ihrer Galerie ändern

Sehen wir uns nun gemeinsam an, wie Sie das Erscheinungsbild Ihrer Galerie ändern, also das Aussehen der Website, auf der Ihre Fotos angezeigt werden.

Klicken Sie im Menü links im Administrationsbereich auf Konfiguration > Erscheinungsbilder.

![Thèmes.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-3788585d.jpg)

Wie Sie sehen, installieren wir Piwigo immer mit zwei standardmässig aktivierten Erscheinungsbildern:

- Modus in der schwarz-weissen Variante: Dieses Erscheinungsbild verwendet Ihre Galerie, wenn Sie sie auf einem Computer aufrufen;
- Smart Pocket: Dieses Erscheinungsbild wird nur auf einem Smartphone oder Tablet angezeigt.

Um das Erscheinungsbild Modus anzupassen, klicken Sie auf „Konfiguration“.

![Modus EN.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-634d2774.jpg)

Es erscheint eine Liste mit 18 Farbstilen (auch „Skins“ genannt), die Varianten des Erscheinungsbilds Modus sind. Bei jedem Skin können Sie auf die Schaltfläche „Vorschau“ klicken, um ein grösseres Beispiel zu sehen.

![Configuration Modus.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-03e94e93.jpg)

Wählen Sie einen Farbstil, der Ihnen gefällt (zum Beispiel Swimming Pool).

Sie können auch mehrere Einstellungen ändern:

- Grösse und Format der Vorschaubilder Ihrer Fotos (standardmässig quadratische Vorschaubilder mit 250 x 250 Pixeln)
- ein Banner für Ihre Galerie anzeigen

Klicken Sie auf „Einstellungen sichern“. Klicken Sie oben links auf dem Bildschirm erneut auf „Galerie“: Ihre Änderungen wurden auf Ihre Galerie angewendet!

![Swimming Pool.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4c236f7a.jpg)

Sehen wir uns nun an, wie Sie ein anderes Erscheinungsbild für Ihre Galerie wählen.

Kehren Sie dazu in den Administrationsbereich zurück und öffnen Sie Konfiguration > Erscheinungsbilder.

Installieren Sie zum Beispiel das Erscheinungsbild Bootstrap Darkroom in Ihrer Galerie.

Klicken Sie in der Liste der deaktivierten Erscheinungsbilder unter Bootstrap Darkroom auf „Aktivieren“.

![Bootstrap Darkroom.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-8ced9cd5.jpg)

Dieses Erscheinungsbild ist jetzt in Ihrer Galerie verfügbar, wird aber noch nicht standardmässig angezeigt: Dazu müssen Sie auf „Als Standard einstellen“ klicken.

![BD Default.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-eb60b4aa.jpg)

Klicken Sie nun auf „Konfiguration“.

![BD Configuration.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-9c15ce03.jpg)

Wie Sie sehen, bietet das Erscheinungsbild Bootstrap Darkroom mehr Konfigurationsoptionen als Modus.

Über das Dropdown-Menü können Sie alle verfügbaren Farbstile durchgehen.

![BD Options.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-f101fede.jpg)

Jedes Mal, wenn Sie einen der Farbstile auswählen, wird eine Vorschau auf dem Bildschirm angezeigt. Wählen Sie zum Beispiel die Option „Material Blue“.

![BD Blue.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-c07d1f41.jpg)

Entdecken Sie auch alle anderen verfügbaren Optionen für Ihr Erscheinungsbild: ein Logo, ein Banner, eine Bildunterschrift hinzufügen…

Weitere Optionen finden Sie auf den Registerkarten „Komponenten“ und „Soziale Netzwerke“.

Belassen wir es für den Moment dabei und klicken Sie auf „Einstellungen sichern“.

Kehren Sie mit der Schaltfläche „Galerie“ oben links zu Ihrer Galerie zurück.

Wie Sie sehen, hat sich das Aussehen Ihrer Galerie komplett verändert!

![BD Blue Demo.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-d54c3669.jpg)

Um aus Ihrer Galerie mit Bootstrap Darkroom in den Administrationsbereich zurückzukehren, klicken Sie oben rechts auf Ihren Benutzernamen und dann auf „Administration“.

![Demo settings.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-bf9fd395.jpg)

Öffnen wir noch einmal Konfiguration > Erscheinungsbilder für ein letztes Detail.

Wie Sie sehen, ist in Ihrer Galerie standardmässig das mobile Erscheinungsbild Smart Pocket aktiviert.

Dieses Erscheinungsbild wird nur angezeigt, wenn Ihre Galerie auf einem mobilen Gerät (Smartphone, Tablet) aufgerufen wird.

![Active themes.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-fac162ff.jpg)

Wie das aussieht, sehen Sie, wenn Sie Ihre Galerie auf Ihrem Smartphone aufrufen.

![Das Erscheinungsbild Smart Pocket](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-801e96cc.jpg)

## Benutzer einladen

Piwigo macht viel mehr Spass, wenn mehrere Personen es nutzen.

So laden Sie andere Personen ein. 

Klicken Sie im Administrationsbereich im Menü links auf Benutzer > Verwaltung.

Im Moment ist der einzige Benutzer in Ihrem Konto derjenige, den Sie bei der Registrierung angelegt haben. Mit diesem Benutzer sind Sie gerade auch angemeldet.

![Manage users.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-93616c57.jpg)

Mit einem Klick auf den Stift links in der Zeile Ihres Benutzers können Sie einige Angaben zu Ihrem Benutzer ändern:

- Benutzername
- E-Mail-Adresse
- Passwort
- ...
    
    ![User management.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2604e62b.jpg)
    

Das Feld „Status“ ist jedoch ausgegraut: Ihr Benutzer hat den Status Webmaster und damit alle Rechte in Ihrer Galerie. Diesen Status können Sie nicht ändern.

Klicken Sie in der Benutzerverwaltung auf „Benutzer hinzufügen“.

![Add new user.jpg](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-b82cf306.jpg)

Geben Sie einen Benutzernamen ein: Das wird der Benutzername der Person, die Sie einladen.

Wählen Sie ein Passwort oder lassen Sie Piwigo ein zufälliges Passwort erzeugen (das ist viel sicherer!).

Geben Sie die E-Mail-Adresse der Person ein, die Sie einladen möchten. Aktivieren Sie „Verbindungseinstellungen via E-Mail senden“.

Die eingeladene Person erhält eine E-Mail mit ihren Zugangsdaten, um sich bei Piwigo anzumelden.

Standardmässig hat der neue Benutzer in Ihrer Galerie den Status „Benutzer“. Er kann sich also bei der Galerie anmelden und die privaten Alben ansehen, für die Sie ihm Zugriff gegeben haben, aber nicht auf den Administrationsbereich zugreifen.

Wenn Sie ihm den Status Administrator geben möchten, klicken Sie links auf den Stift, um den Status zu ändern. Wählen Sie im Feld „Status“ im Dropdown-Menü „Administrator“ aus und klicken Sie auf „Aktualisieren“.
