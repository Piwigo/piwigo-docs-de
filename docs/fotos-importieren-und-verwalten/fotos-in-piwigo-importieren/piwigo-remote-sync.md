# Dokumentation: Piwigo Remote Sync

## Piwigo Remote Sync: Was ist das?

Piwigo Remote Sync ist ein Werkzeug zur Dateiübertragung für Piwigo.

Damit können Sie eine Ordnerstruktur auf Ihrem Computer mit Ihrer Piwigo-Galerie synchronisieren.

## Piwigo Remote Sync: Wie funktioniert es?

Das Prinzip ist einfach: Piwigo Remote Sync erstellt automatisch Alben, die der Struktur Ihrer lokalen Ordner entsprechen. Sie können die Synchronisierung beliebig oft starten: Piwigo Remote Sync fügt nur Neues hinzu.

## Piwigo Remote Sync installieren

Um Piwigo Remote Sync zu installieren, laden Sie es einfach [auf dieser Seite](https://de.piwigo.org/ext/index.php?eid=851) über die Schaltfläche „Download“ herunter.

Die App besteht aus einer Datei namens remotesync-ui.jar. Doppelklicken Sie einfach auf diese Datei, um die App zu starten. Piwigo Remote Sync läuft unter Windows, Mac und Linux.

Haben Sie Probleme bei der Installation oder beim Starten von Piwigo Remote Sync?

Lesen Sie die folgenden häufigen Fragen.

### Häufige Fragen zu Piwigo Remote Sync

- **Fehlermeldung: Unable to locate Java Runtime**
    
    Piwigo Remote Sync benötigt Java Runtime. Diese Komponente ist nötig, um Programme auszuführen, die mit Java entwickelt wurden. [Laden Sie Java Runtime von der offiziellen Seite herunter](https://www.java.com/download/manual.jsp).
    
- **Fehlermeldung unter macOS: Die App kann nicht geöffnet werden, da sie von einem nicht verifizierten Entwickler stammt**
    
    Auf neueren Mac-Computern kann beim Doppelklick auf die Datei remotesync-ui.jar die Meldung „Die App kann nicht geöffnet werden, da sie von einem nicht verifizierten Entwickler stammt“ erscheinen.
    
    1. Suchen Sie die Datei remotesync-ui.jar im Finder Ihres Mac.
        
        ![](https://help.apple.com/assets/63BCA927AAE78C58DD7FBE35/63BCA92EAAE78C58DD7FBE76/fr_FR/058e4af8e726290f491044219d2eee73.png)
        
        Verwenden Sie nicht das Launchpad. Im Launchpad steht das Kontextmenü nicht zur Verfügung.
        
    2. Klicken Sie bei gedrückter Control-Taste (ctrl) auf remotesync-ui.jar und wählen Sie im Kontextmenü „Öffnen“.
    3. Klicken Sie auf „Öffnen“.
        
        Die App wird als Ausnahme in Ihren Sicherheitseinstellungen gespeichert. Danach können Sie sie wie jede andere registrierte App per Doppelklick öffnen.
        

## Piwigo Remote Sync verwenden

Wenn Sie Piwigo Remote Sync starten, öffnet sich das folgende Fenster.

![piwigo-remote-sync.png](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4b3b57e5-me.png)

Geben Sie die URL Ihrer Galerie sowie Ihren Benutzernamen und Ihr Passwort ein.

Wählen Sie dann den Ordner auf Ihrem Computer, den Sie mit Piwigo synchronisieren möchten, indem Sie auf das Symbol ... klicken.

![piwigo-remote-sync.upload.png](https://ressources.piwigo.com/i?/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-1a7d31fb-me.png)

Klicken Sie auf „Upload“: Die Übertragung beginnt. Die synchronisierten Fotos werden auf dem Bildschirm angezeigt.
