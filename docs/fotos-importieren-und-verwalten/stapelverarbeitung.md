# Stapelverarbeitung: Eine Auswahl von Fotos bearbeiten und verwalten

**Wie kann ich in Piwigo eine Auswahl von Dateien gesammelt bearbeiten, löschen oder aktualisieren?**

Genau dafür gibt es die Stapelverarbeitung.

Mit der Stapelverarbeitung wählen Sie anhand verschiedener Kriterien eine Reihe von Dateien aus, um sie zu bearbeiten oder zu löschen.

Sie können auch beim Durchsuchen der Galerie eine Auswahl von Fotos zusammenstellen, indem Sie sie in den Sammelkorb legen. Diese Fotos bearbeiten Sie danach im Administrationsbereich mit der Stapelverarbeitung.

Die Stapelverarbeitung gehört zu den leistungsstärksten Funktionen von Piwigo und spart Ihnen enorm viel Zeit. Nehmen Sie sich also die Zeit, sich damit vertraut zu machen!

## Stapelverarbeitung: Einführung

Um die Stapelverarbeitung zu öffnen, gehen Sie in den Administrationsbereich und wählen im linken Menü Fotos > Stapelverarbeitung.

![Stapelverarbeitung](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-5509dea2.jpg)

Diese Seite hat zwei Tabs:

- Übersicht (Standard)
- Einzelmodus

Im Tab „Übersicht“ stellen Sie anhand vieler Kriterien eine Auswahl von Fotos zusammen und bearbeiten sie gesammelt.

Die Seite ist in drei Bereiche gegliedert:

- Filter: In diesem Bereich stellen Sie die Dateien zusammen, die Sie aktualisieren möchten. Dazu kombinieren Sie die zahlreichen verfügbaren Kriterien.
- Auswahl: Dieser Bereich zeigt das Ergebnis Ihrer Filterkriterien. Sie können die Auswahl verfeinern, indem Sie einzelne Dateien an- oder abwählen.
- Aktion: In diesem Bereich wählen Sie die Aktion, die auf Ihre Auswahl angewendet werden soll.

## Stapelverarbeitung: Filter verwenden

Standardmässig ist der zuletzt verwendete Filter aktiv. Meistens ist das der letzte Import.

Mit einem Klick auf das Kreuz entfernen Sie diesen Filter.

![Animation](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-1d015b12.gif)

Mit einem Klick auf **Einen Filter hinzufügen** wählen Sie aus den verfügbaren Kriterien die Filter für Ihre Auswahl.

![Einen Filter hinzufügen](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-9d29322d.jpg)

Wenn Sie einen Filter hinzufügen, werden die passenden Fotos nicht automatisch angezeigt. Um das Ergebnis Ihrer Auswahl zu sehen, klicken Sie auf **Fotoset aktualisieren**.

### Fotos nach Album filtern

Mit dem Filter „Album“ wählen Sie ein Album aus, um dessen Dateien anzuzeigen.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-d4f8929c.png)

Um ein Album auszuwählen, klicken Sie auf die Schaltfläche. Daraufhin öffnet sich das Fenster für die Albumsuche.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-faf44dfe.png)

Nutzen Sie die Suche oder blättern Sie durch die Liste und klicken Sie auf das +, um das Album auszuwählen.

Nachdem Sie ein Album gewählt haben, können Sie auch die Fotos seiner Unteralben in die Auswahl aufnehmen. Aktivieren Sie dazu **Unteralben miteinbeziehen**.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-bbd4e67c.png)

### Fotos nach Schlagwort filtern

Mit dem Filter „Schlagworte“ filtern Sie Fotos nach Schlagworten. Sie können mehrere Schlagworte eingeben und festlegen:

- ob nur Dateien angezeigt werden, die ALLE gewählten Schlagworte haben (Alle Schlagworte)
- oder ob Dateien angezeigt werden, die mindestens eines der gewählten Schlagworte haben (Beliebiges Schlagwort)

![Nach Schlagwort filtern](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-9de126af.jpg)

### Fotos nach Datenschutzstufe filtern

Mit dem Filter „Datenschutzstufe“ zeigen Sie nur Dateien mit einer bestimmten Datenschutzstufe an:

- Jeder
- Kontakte
- Freunde
- Familie
- Administratoren

Mit der Option **Fotos mit geringerer Privatsphäre einschliessen** können Sie mehrere Datenschutzstufen zusammenfassen.

![Nach Datenschutzstufe filtern](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4572f8d4.jpg)

Ein Beispiel: Wenn Sie die Datenschutzstufe „Freunde“ wählen und diese Option aktivieren, werden Fotos mit den Datenschutzstufen „Freunde“ UND „Kontakte“ angezeigt.

Wie Datenschutzstufen funktionieren, erfahren Sie [in diesem Artikel](../benutzer-verwalten/datenschutzstufen.md).

### Fotos nach Abmessungen filtern

Mit dem Filter „Abmessungen“ filtern Sie Fotos nach ihren Abmessungen:

- Breite
- Höhe
- Verhältnis von Breite zu Höhe (Format)

![Nach Abmessungen filtern](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-5355d5b9.jpg)

Um den gewünschten Bereich festzulegen, verschieben Sie einfach die Schieberegler wie im Beispiel oben.

Wenn Sie ein bestimmtes Format suchen (Hochformat, Querformat, Panorama), klicken Sie auf die entsprechende Bezeichnung. Das Verhältnis wird dann automatisch angepasst.

### Fotos nach Dateigrösse filtern

Mit dem Filter „Dateigrösse“ filtern Sie Fotos nach ihrer Grösse in MB (Megabyte).

![Nach Grösse filtern](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-34cb25ce.jpg)

### Ein Foto per Stichwort suchen

Der Filter „Suchen“ blendet ein Textsuchfeld ein.

![Suchfilter](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-f12b73ba.jpg)

Die Suche funktioniert genauso wie die Suche in Ihrer Galerie.

Klicken Sie auf **Tipps zur Suche**, um leistungsstarke Suchfunktionen kennenzulernen.

### Fotos mit vordefinierten Filtern filtern

Piwigo bietet standardmässig viele vordefinierte Filter für häufige Aufgaben.

Folgende Filter sind standardmässig verfügbar:

- Letzter Import: zeigt die zuletzt importierten Fotos (den letzten Import sehen Sie auch über das Menü Fotos > Neueste Fotos)
- Duplikate: findet alle doppelten Fotos (mit gleichem Namen) in Ihrer Fotobibliothek, damit Sie die Duplikate entfernen können
- Meine Favoriten: findet die Fotos, die Sie in der Galerie zu Ihren Favoriten hinzugefügt haben
- Sammelkorb: findet alle Fotos, die Sie in Ihren Sammelkorb gelegt haben (Sie können auch das Menü Fotos > Sammelkorb verwenden, siehe Abschnitt zum Sammelkorb)
- Ohne Album (verwaiste Fotos): findet Fotos in Ihrer Galerie, die keinem Album zugeordnet und deshalb nicht sichtbar sind
- Ohne Schlagwort
- Alle: zeigt alle Fotos in Ihrer Bibliothek

![Vordefinierter Filter](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2767c70f.png)

### Mehrere Filter kombinieren

Sie können problemlos mehrere Filter kombinieren.

Nachdem Sie den ersten Filter gewählt haben, klicken Sie erneut auf **Einen Filter hinzufügen**. Die Filter werden dann kombiniert.

![Kombinierte Filter](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-65282181.png)

### Batch Manager Prefilters: Neue vordefinierte Filter zur Stapelverarbeitung hinzufügen

Um neue vordefinierte Filter hinzuzufügen, installieren Sie das Plugin **Batch Manager Prefilters**.

Es fügt folgende Filter hinzu:

- nur einem Album zugeordnet
- mehreren Alben zugeordnet
- mit Autor
- ohne Autor
- mit Schlagworten
- ohne Erstellungsdatum
- ohne Titel

Sie können auch das Plugin **Batch Manager, Description** installieren, um den vordefinierten Filter „ohne Beschreibung“ hinzuzufügen.

So sehen Sie auf einen Blick alle Fotos ohne Beschreibung.

### Batch Manager Added By: Ein Foto nach Benutzer suchen

Um Fotos nach dem Benutzer zu filtern, der sie in Piwigo hochgeladen hat, installieren Sie das Plugin **Batch Manager, Added By**.

!!! info "Wenn Sie Kunde eines Piwigo-Cloud-Tarifs sind, ist dieses Plugin erst ab dem Tarif Team verfügbar"

Nach der Aktivierung fügt dieses Plugin der Stapelverarbeitung den neuen Filter „Hinzugefügt von“ hinzu.

## Stapelverarbeitung: Ihre Auswahl

Sobald Sie alle Filter angewendet und auf **Fotoset aktualisieren** geklickt haben, erscheinen die passenden Fotos im Bereich „Auswahl“.

Standardmässig werden 20 Dateien angezeigt. Mit den Seitenzahlen oder den Pfeilen unten rechts blättern Sie durch Ihre Auswahl. Unten links können Sie mit 50, 100 oder „Alle“ mehr Dateien auf einmal anzeigen.

![Auswahl in der Stapelverarbeitung](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-ee1d3fa6.jpg)

Um die zu bearbeitenden Dateien auszuwählen, klicken Sie einfach auf jede einzelne Datei. Sie können auch auf Folgendes klicken:

- „Die ganze Seite“, um alle Dateien auf dem Bildschirm auszuwählen
- „Das ganze Set“, um alle Dateien Ihrer Auswahl auszuwählen
- „Invertieren“, um alle Dateien ausser den angeklickten auszuwählen
- „Nichts“, um alle ausgewählten Dateien abzuwählen

Ausgewählte Dateien sind mit einem orangefarbenen Symbol markiert.

![Animation](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-bf8ae1c3.gif)

Sie können in der Übersicht auch eine einzelne Datei bearbeiten.

Fahren Sie dazu mit der Maus über das Vorschaubild des Fotos und klicken Sie auf das Stift-Symbol.

![Symbol Foto bearbeiten](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-3fe27552.jpg)

Die Bearbeitungsseite des Fotos öffnet sich in einem neuen Tab. Nehmen Sie die gewünschten Änderungen vor und speichern Sie sie mit **Einstellungen sichern**. Schliessen Sie dann den Tab und kehren Sie zur Übersicht zurück, um mit Ihren Änderungen fortzufahren.

## Stapelverarbeitung: Ausgewählte Dateien gesammelt bearbeiten

Wenn Sie die zu bearbeitenden Fotos ausgewählt haben, klicken Sie auf **Aktion auswählen**. Die Dropdown-Liste zeigt alle Änderungen, die Sie an Ihrer Auswahl vornehmen können:

- Ausgewählte Fotos entfernen
- Mit einem Album verbinden
- Ins Album verschieben
- Von Album abtrennen
- Schlagworte hinzufügen
- Den Autor festlegen
- Titel festlegen
- Erstellungsdatum festlegen
- Wer soll diese Fotos sehen können? (Datenschutzstufe)
- Synchronisieren von Metadaten
- In den Sammelkorb (wenn Ihr Sammelkorb leer ist)
- Aus Sammelkorb entfernen (wenn der Filter „Sammelkorb“ ausgewählt ist)
- Mehrfache Bildgrössen entfernen
- Mehrfache Bildgrössen generieren
- Videos (spezielle Aktionen für Videodateien)

![Aktion auswählen](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-8ee09784.jpg)

### Beispiel: Den Titel der Fotos ändern

Sie haben Dateien in Piwigo hochgeladen, deren Namen von der Kamera erzeugt wurden. Der Titel wird standardmässig aus dem Dateinamen übernommen (IMG_4545, IMG_4546…).

Sie möchten vor den aktuellen Namen eine aussagekräftige Bezeichnung setzen.

Wählen Sie nach dem Hinzufügen der Dateien die Aktion **Titel festlegen**.

Geben Sie in das Eingabefeld den Titel ein, den Ihre Dateien erhalten sollen, hier: „beach“.

![Titel festlegen](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-feabe8d9.jpg)

Klicken Sie auf **Aktion anwenden**. Der Titel der Dateien lautet nun „beach(IMG_XXXX.JPG)“.

### Beispiel: Einer Auswahl ein Schlagwort hinzufügen

Um einer Auswahl ein Schlagwort hinzuzufügen, klicken Sie auf Aktion auswählen > Schlagworte hinzufügen. Wählen Sie ein vorhandenes Schlagwort aus der Liste oder geben Sie Text ein, um ein neues Schlagwort anzulegen.

![Schlagworte hinzufügen](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-d52c4ba4.jpg)

Klicken Sie auf **Aktion anwenden**. Das Schlagwort wurde Ihren Fotos hinzugefügt.

### Posted Date Changer: Das Hinzufügedatum mit der Stapelverarbeitung ändern

Das Hinzufügedatum einer Auswahl von Fotos nach dem Hochladen zu ändern, kann sehr nützlich sein. Diese Aktion ist in Piwigo standardmässig aber nicht verfügbar. Um sie hinzuzufügen, aktivieren Sie das Plugin **Posted Date Changer**.

Nach der Aktivierung des Plugins steht in der Stapelverarbeitung die Aktion „Change Posted Date“ zur Verfügung.

## Stapelverarbeitung: Einzelmodus

Mit der Stapelverarbeitung können Sie Ihre ausgewählten Dateien auch einzeln bearbeiten.

Wechseln Sie dazu in den Tab „Einzelmodus“.

![image.png](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-ba1e1bbe.png)

Diese Seite zeigt alle Dateien, die den Filtern aus dem ersten Tab entsprechen.

!!! warning "Achtung:"
    Wenn Sie diese Filter ändern, klicken Sie unbedingt auf **Fotoset aktualisieren**. Damit wird auch die Auswahl im Tab „Einzelmodus“ aktualisiert.

So können Sie für jede Datei den Titel, den Autor, das Erstellungsdatum, die Datenschutzstufe, die Schlagworte, die zugeordneten Alben und die Beschreibung bearbeiten.

Vergessen Sie nicht, unten auf der Seite auf **Absenden** zu klicken, um Ihre Änderungen zu speichern.

## Den Sammelkorb in Piwigo verwenden

Wie im vorherigen Abschnitt erklärt, können Sie in Piwigo einen „Sammelkorb“ anlegen. Er enthält eine Auswahl von Dateien, die Sie für später zurücklegen.

In Ihrer Galerie legen Sie ein Foto in den Sammelkorb, indem Sie auf der Seite des Fotos auf die Schaltfläche **In den Sammelkorb** klicken.

Je nach Erscheinungsbild sieht das Symbol wie ein Einkaufswagen, eine Fahne oder ein Korb aus. Bei Modus, dem Standard-Erscheinungsbild von Piwigo, ist es ein Einkaufswagen.

![In den Sammelkorb](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-4df4feba.jpg)

Sie können auch alle Fotos eines Albums in den Sammelkorb legen, indem Sie auf der Albumseite auf das Symbol **In den Sammelkorb** klicken.

![Symbol In den Sammelkorb](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-72835069.jpg)

Wenn Ihre Auswahl fertig ist, wechseln Sie in den Administrationsbereich, um Ihren Sammelkorb anzusehen.

Klicken Sie dazu auf das Menü Fotos > Sammelkorb. Dieses Menü zeigt jederzeit die Anzahl der Dateien in Ihrem Sammelkorb an.

![Linkes Menü](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-2a93dea6.jpg)

Das Menü „Sammelkorb“ zeigt einfach die Stapelverarbeitung an, gefiltert mit dem vordefinierten Filter „Sammelkorb“.

Um den Sammelkorb zu leeren, klicken Sie unter dem Filter auf die Schaltfläche **Sammelkorb leeren**.

![Sammelkorb leeren](https://ressources.piwigo.com/uploads/c/v/7/cv7jpz6hf8/2026/07/03/20260703190344-dc919217.jpg)
